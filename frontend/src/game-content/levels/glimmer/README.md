# 微光

专属场景“暮野萤光”以日落后的原野、天边余晖与几点萤火呼应曲名。天空中央保持低对比，余晖、小径和萤火集中在右侧竖屏安全取景区。场景为原生 480×270 像素画，资源声明、取景与暖灰道路配色由 `index.ts` 维护；不修改基础节奏关卡共用的排练室。

美术源为 `art/glimmer.px.js`；重建见[内容制作入口](../../README.md)。

## 音乐编配

采用 GS 钢琴击拍旋律、电钢琴和声、指弹贝斯与标准鼓组，保留原有音符、108 个敲击目标、路线、100 BPM 和四个段落。声部由谱面显式声明，伴奏音符通过共用和弦模板生成；鼓组使用底鼓、边击和闭合踩镲的 GM 键位。

关卡只保留这一份正式编配。音源来源见[公共音源说明](../../shared/audio/README.md)，任意声部和命中映射见[架构说明](../../../../../docs/ARCHITECTURE.md#声音与试听)。
