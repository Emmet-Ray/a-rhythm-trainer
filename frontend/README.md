# 节奏训练前端

使用 React、TypeScript、Vite 和 React Router，谱面由 VexFlow 绘制。

## 常见节奏型输入

自定义新建页沿用练习工作区：顶部提供试听、名称和保存，主区提供谱面及编辑工具，设置侧栏提供节拍器、速度和小节数量。窄屏设置移至谱面上方，工具栏自然换行；保存错误在顶部显示，超拍提示仍位于编辑工具附近。小节删除确认、草稿恢复及保存流程保持原有规则。

编辑器提供二平均、四平均、前八后十六、前十六后八、小附点、反小附点、小切分、大附点、反大附点、大切分十种快捷输入。后三种各占两拍，其余各占一拍（以四分音符为一拍）。基础工具与常见节奏型常驻并排，空间不足时上下排列；共用附点、删除末尾及清空操作。快捷输入一次追加整组普通音符，超拍时整组拒绝，不改变数据格式，添加后仍可逐音符编辑；三连音继续按原有分组规则处理。

## 页面返回恢复

练习详情共用紧凑题头：预设和自定义显示返回入口及原题名，随机练习仅显示返回入口。题头不重复主题、模式或存储来源，宽屏一行优先，长题名自然换行；返回仍使用原有历史恢复机制。

浏览器后退／前进恢复对应历史记录的状态与滚动；新访问浏览列表继承本次会话的最近选择和位置。预设保留模式、主题及两栏滚动，练习记录保留筛选与加载数量，自定义列表按身份及模式保留分页。设置侧栏入口记住上次分类，显式 URL 分类优先。随机、自定义的侧栏仍进入模式选择页，不自动跳进练习或编辑器。练习和编辑页的新访问从顶部开始。页面内“返回”链接优先回到当前会话已有的目标历史记录，没有已知来源时按普通链接打开；修饰键和新标签打开保留原生行为。

预设列表在右栏主题标题旁统一选择击拍或听写，长标题或窄屏时自然换行。桌面右栏标题与模式固定，下方题目列表和左侧主题导航各自滚动，不带动全站导航或另一栏。切换主题或模式时题目列表归零，返回列表时恢复两栏滚动位置。窄屏改用主题选择框和普通页面滚动。切换主题不改变训练模式，无对应题目时显示空状态，不展示未开放模式。

`navigation/PageVisits` 不缓存服务器数据或组件。`useBrowsingState` 让新访问继承最近浏览偏好，同时为每次访问独立保留快照；`useVisitState` 仅用于该次访问的状态，不跨新访问继承。路由内容仍按历史记录 key 挂载。新增异步页面的加载占位须标记 `data-navigation-pending`，内容就绪后才恢复滚动；用户主动滚动会取消恢复。账号题库重新获取原分页数据，空页退到最近有效页；分页和滚动按身份隔离。

快照仅保存在当前应用实例内，刷新或关闭页面后不保留。自定义新建草稿也按历史访问保存名称、小节内容、选中小节及生效的 BPM／节拍器开关，身份和模式隔离；返回原记录恢复，重新点击“新建”创建空草稿。保存失败保留，确认成功后仅清除提交版本，不清除离开后继续编辑的新版本；不自动保存到题库。不恢复谱面内部滚动。离开练习仍卸载播放器并停止音频，不恢复播放、预备拍或正在运行的轮次；主题与击拍精度继续使用已有偏好存储。

随机练习按历史记录保留生成配置和当前题目，返回不重新生成，已有题目时不自动展开设置抽屉。听写三种来源共用 `PracticeWorkspace` 的作答快照，恢复答案、选中小节、逐小节验证结果、播放范围及生效设置。`DictationState` 以题目内容和题目编号共同校验绑定：换题即使内容相同也清空作答，同编号自定义题内容变化后也不沿用旧答案；自定义来源按账号／本地身份隔离。听写组件只接收作答状态，不直接访问路由存储。结果遮罩、参考答案显示状态、音频与预备拍不恢复；新访问从默认状态开始。

随机生成配置跨新访问保留，重新进入模式时按该配置生成新题目；空范围保留并提示选择，不回退默认范围。历史返回仍恢复当次题目，不重新生成。浏览偏好只存在于当前应用实例，刷新后重置，URL 中的设置分类仍有效；不扩展答案、草稿、播放或弹窗的恢复范围。

回归检查：侧栏切换后预设选择和记录筛选保留，历史返回仍恢复原快照；刷新重置会话偏好；设置入口回到上次分类；随机配置保留但新访问不沿用旧题；账号分页及滚动隔离、删除后空页回退；直接打开题目时返回入口可用。

## 练习交互

预设题头提供上一题／下一题，仅在当前主题、当前训练方式内切换，首尾禁用，不自动跳题。切题通过路由卸载旧工作区，停止声音和未完成的启动请求。三种来源在题头提供当前内容版本的本地练习历史，复用记录详情抽屉；历史成就与本次结果分开展示，听写区分独立完成与查看答案后完成。账号状态仍沿用既有记录权限，不读取游客数据。

题名旁只显示历史完成状态：击拍「✓ 已通过」，听写「✓ 已独立完成／✓ 已完成」；未完成不显示状态。有记录即可打开历史，无记录时入口禁用。切题和随机生成设置统一放在题头右侧，本次结果仍在练习工具栏。

击拍快捷键：`H` 开始、`L` 试听、`S` 停止（含声音准备阶段），空格击拍；预设切题：`P / N`；随机换题：`N`（播放期间禁用）。工具栏「快捷键」浮层只列出当前模式及来源支持的操作，点击外部、关闭按钮或 `Esc` 收起；按钮悬停提示对应键位。输入框、可编辑区域、链接／按钮聚焦、弹窗或快捷键说明打开及输入法组合输入时不触发全局练习快捷键。记录粒度、存储格式及已有历史返回恢复规则不变。

听写“查看答案”在原谱面窗口切换为只读参考谱面，不再在页面底部展开。参考模式明确标注“参考答案”，编辑工具和验证按钮不可操作但保留占位；点击“返回作答”恢复原草稿、选中小节、验证状态及横向滚动位置。参考谱面与草稿分别渲染，答案不会传入草稿编辑回调，查看答案不会触发通过结果；播放操作仍保留原有含义。

听写顶部的“仅播放当前小节”同时控制题目和我的答案：默认不勾选，播放整题；勾选后显示当前小节编号，播放所选小节。切换范围仍停止当前播放，保留草稿与验证结果。

作答、编辑与参考答案共用单行谱面：宽屏双小节利用可用宽度，长题和窄屏在谱面窗口内左右滚动，编辑工具不随横向滚动移动。同宽窗口下，小节宽度、符号倍率和谱面高度不随小节数量变化；单小节左对齐，右侧留白。小节宽度按十六分音符容量预留，增删音符不改变小节边界或重置滚动位置；空小节不补休止符，编号使用 VexFlow 内置小节号。

谱面上方的小节导航列出全部小节并突出当前项。点击数字同步编辑位置，仅在目标未完整可见时横向定位；点击谱面也同步导航，手动滚动不改变选中小节。返回恢复草稿时，等待窗口宽度就绪后将选中小节带入视野一次（窄屏对齐小节起点），不恢复精确的历史横向位置；随后编辑、手动滚动或调整窗口尺寸不自动拉回。参考答案使用独立的浏览导航，不影响作答的选择及滚动位置；两种模式保留相同的导航行高度。

当前支持击拍练习、节奏听写，以及预设、随机和自定义三种题目来源；几何游戏未开放。已接入短信登录、会话恢复与退出，以及账号自定义练习的保存、列表和练习读取。

```sh
cd frontend

```

## 练习控件

预设与自定义题目区最大宽度为 720px，在公共框架内左对齐；题目使用最小高度 64px 的整行链接与淡分隔线，悬停显示浅色底，键盘聚焦显示轮廓。预设模式切换宽屏位于主题标题旁，窄屏移至标题下方，自定义“新建练习”位于题目区上方并右对齐；窄屏随可用宽度收缩，长题名换行。首页和模式入口也使用共用导航行样式，保留各自的图标与说明。

全站桌面采用固定侧栏导航，支持折叠为图标；视口宽度不超过 1000px 时改用移动页头和菜单抽屉。正文最大内容宽度为 1440px，结合导航占位及响应式左右留白收缩。功能页标题、返回栏与内容外边界遵循统一正文基准线，较窄的列表与设置内容在公共框架内左对齐；预设主题导航与设置分类共用侧栏宽度和列间距，窄屏改为上下布局。账号登录表单在设置内容区左对齐并限宽 400px。页面、工作区及谱面颜色使用语义变量，支持浅色与深色模式。

击拍工作区顶部整行放击拍／试听按钮，下方分为左侧谱面与反馈、右侧节拍器与 BPM 设置栏。窄屏时顶部工具栏换行，下方设置与谱面上下排列，不重建训练或重置设置。谱面按可用宽度适度放大（最高 1.6 倍），排版和反馈共用缩放坐标。预设、随机和自定义击拍共用。

听写与击拍共用 `PracticeFrame` 布局：顶部通栏左侧放“播放题目／播放我的答案”和播放范围，右侧保留随机练习的生成操作；下方左侧为作答／参考谱面窗口、编辑工具和验证操作，右侧放同一套节拍器与 BPM。窄屏自动换行并上下排列。框架不持有播放或作答状态，调速／切换范围仍只重建播放器，保留草稿与验证结果，换题才重置作答；自定义新建页沿用相同的工作区布局规则，顶部放名称、试听和保存，设置区放节拍器、BPM 与小节数量；设置在 DOM 中先于谱面，宽屏置右、窄屏置上。

随机击拍与听写首次进入即按默认范围生成两小节题目，不自动播放、不自动打开设置；同一历史记录返回时恢复原题及配置，不重复生成。生成配置放在右侧抽屉，窄屏占满宽度。标题、小节数和练习范围标题固定在顶部，空选或生成失败的提示紧跟范围标题，不随选项滚动。范围分为音符、休止符、节奏型三个分组，每项独立勾选并显示真实记谱图形；音符与休止符宽屏双列、窄屏单列，节奏型单列，整个选项区独立滚动。抽屉不提供生成或提交按钮，支持关闭按钮、Esc 和遮罩关闭；关闭保留当前历史记录内的材料、小节数选择，不立即换题，也不保存到浏览器。修改配置后仅通过工作区“换一题”应用新配置出题，失败打开抽屉提示；范围为空时禁用生成。音频准备及播放期间禁用生成和设置入口，换题保留 BPM 与节拍器设置。预设和自定义练习不显示这些入口。

随机范围表示允许使用的材料，不保证每题覆盖全部选项。默认选中全音符、二分音符和四分音符；支持单独音符、附点四分／八分音符、五种休止符及十一种节奏型（含小三连）。节奏型整组生成，无需勾选其基础音符；普通材料按自身网格放置，附点四分／八分音符与一拍节奏型从拍头开始，两拍节奏型从第 1、3 拍开始。生成器只使用勾选材料，无法填满 4/4 小节时提示增加其他材料，不自动补入未选音符或休止符。编辑器快捷输入和随机组合复用 `rhythm/RhythmPatterns.ts` 定义，显示预览与生成内容保持一致。

击拍谱面使用 VexFlow 内置小节序号，编号位于对应小节左上方；滚动窗口根据屏幕高度容纳完整的一至两行。击拍／试听按音频时钟定位的事件（含休止符）跟随谱行，两行窗口保留当前行与下一行；滚动采用按行切换，不连续移动音符，也不重建谱面或改变判定。滚轮、触摸、滚动条或方向／翻页键操作会暂停本轮跟随，可点击“继续跟随”恢复。停止或结束后保留位置供复盘，新一轮回到首行并恢复跟随；听写和编辑谱面不受影响。

音频加载时仅对应的开始／试听按钮显示“准备中…”。预备拍用半透明深色遮罩压暗谱面可视窗口，中央显示倒数（默认 4、3、2、1），读取现有音频时钟，点击不关闭，正式开始立即消失，不增加额外拍。击拍过程只保留音符下方的判定标记。自然结束后在工具栏显示“✓ 本次通过／× 本次未通过”，保留谱面标记，不使用结果遮罩或 Toast。重新开始或调整配置会清除旧结果；试听结束和手动停止不显示结果。结果区域预留空间，避免出现时改变工具栏高度；音频错误也在顶部操作栏提示。

听写复用击拍的 `PracticeCue` 预备拍倒数：播放题目和播放答案的预备拍由原有音频时钟倒数，正式播放、停止、调速、切换范围或小节时清除。单小节验证在对应谱面左上方显示“✓ 正确／× 有错误”，随小节横向滚动；小节导航同步显示红叉或绿勾，紫色仍只表示选中。修改该小节后同时清除两处结果，其他小节不受影响；未验证不显示标记。全部小节验证正确才在工具栏显示“✓ 全部通过”，单小节错误不视为整题失败。查看参考答案和播放结束不触发通过，重新播放或编辑会清除旧整体结果。草稿编辑器与谱面只接受验证状态并统一呈现，不负责判定。

编辑器的“清空当前小节”直接清除当前小节全部内容，不弹确认框；保留小节及选中位置，不影响其他小节。空小节时禁用，清空后移除编辑提示；听写同时重置该小节验证结果，不修改标准答案或已保存的练习。

听写作答与自定义练习共用节奏编辑器：音符、休止符、小三连和附点使用音乐符号按钮，悬停可查看名称，也保留键盘操作和无障碍名称。“删除末尾”保留文字。图形沿用谱面的记谱规则，全／二分休止符带短参考线；工具栏在窄屏自动换行。添加、附点和删除仍作用于当前小节末尾，不改变容量限制。

练习设置中的机械节拍器可点击开启／关闭，与 BPM 控件放在一起。开启后随击拍、试听、听写及自定义试听的音频时钟左右摆动；空闲时不独立发声。中途关闭、停止或调速后摆杆归中，重新开启接上当前拍位；关闭时预备拍声音仍保留。系统启用“减少动态效果”时不摆动，声音和开关照常工作。

练习页面共用 BPM 调速控件（40–240，默认 60）：拖动乌龟／兔子之间的滑块，松手后生效；也可直接输入，失焦或回车生效。回车确认合法数值后退出输入焦点（未修改也退出），空值、越界或非整数则保留焦点并提示。滑块支持键盘方向键和 Home／End。速度真正改变才停止当前练习／播放，不自动重启；击拍谱面保留，只清除本轮反馈。移出轨道松手仍提交，控件失焦或失去指针捕获不回退；真正取消操作（Escape、指针取消或窗口失焦）恢复原速度。非法值保留原速度并提示。听写和自定义编辑草稿不会因改速丢失，速度本身不持久保存。

## 数据保存

- 站点明确关闭账号功能时，沿用游客的本地练习流程；设置页说明未启用账号功能，不提供登录表单。后端断连、503 或无效身份响应不等于功能关闭，自定义练习仍暂停读取和保存，避免误用本地存储。
- 未登录时，自定义练习保存于当前站点的 `localStorage`；已登录时保存到后端，列表只显示当前账号的题目。
- 本地题库与账号题库独立，不自动迁移或合并。更换浏览器、域名或端口不会共享本地数据，清除网站数据会丢失本地练习。
- 未保存的编辑草稿只在当前应用会话内保留，返回原编辑记录可恢复；刷新或关闭页面后丢失。身份尚未确认时先等待，不把账号草稿作为本地草稿打开。
- 游客练习记录保存在当前浏览器，可从侧栏“练习记录”查看；刷新保留历史，但不恢复正在作答的草稿。账号状态下暂不记录，也不展示游客历史；身份未知或服务异常时暂停记录，不回退到游客。
- 登录凭证由后端设置为 HttpOnly Cookie，前端不读取或写入 localStorage；登录、退出不会迁移或删除本地练习。
- 登录、退出及登录状态重试统一位于设置的“账号”分类，主导航不展示独立账号控件。`/login` 以替换历史记录方式跳转到 `/settings?category=account`，站内登录入口直接使用新地址。登录成功后原位显示账号状态，退出成功后原位恢复空表单，不跳回首页。
- 登录表单的手机号与验证码格式错误紧跟对应输入框，并关联辅助说明、标记错误与聚焦；编辑后清除旧错误。发送成功后聚焦验证码框，网络及服务错误保留在提交按钮上方的紧凑反馈区，长提示自然换行。发送冷却和认证流程不变。
- 设置页 `/settings` 提供紫色、蓝色和青绿色配色，以及跟随系统、浅色和深色三种明暗模式，两者独立选择并立即生效。默认紫色并跟随系统，系统明暗变化会在跟随模式下自动应用；谱面、符干和反馈也适配明暗模式。偏好保存在当前浏览器，不要求登录、不与账号或其他标签页实时同步。外观“恢复默认”同时重置配色与明暗模式，不删除本地练习或重置击拍精度。存储失败时仍可临时切换，并显示提示。
- 设置页提供账号、外观、本地数据、声音、击拍精度五个分类：桌面左侧导航、右侧内容，窄屏导航移到上方，手机两列展示全部分类。主题与精度选项按可用宽度自然换行，本地统计限宽；精度说明明确从下一轮生效，清空按钮前说明数据范围，反馈紧跟操作。默认展示账号，分类由 `category` 查询参数决定，未知值回退账号；切换分类替换当前历史记录，刷新和返回保留分类，不增加逐项切换的后退步骤。声音入口标注未开放，暂不提供音色设置。
- 击拍精度提供宽松、标准（默认）、严格三档，完美／命中容差分别为 80／200ms、50／150ms、30／100ms。三种来源的击拍练习共用，开始一轮时固定参数，不改变当前轮次或迟到输入重算，也不影响试听和听写。偏好只保存在当前浏览器，恢复默认只重置击拍精度；保存失败仍供当前页面会话的下一轮使用并提示，刷新后可能恢复标准。与外观偏好一样，暂不自动同步其他已打开标签页，刷新后读取最新保存值。
- 本地数据展示练习总数及击拍、听写数量，不提供练习入口。清空前使用浏览器确认框，确认后仅删除本地练习，不影响主题、登录状态或账号题库。空题库禁用清空；读取失败不显示零，可重试或确认清空损坏数据；删除失败显示错误。每次进入该分类重新读取，暂不实时同步其他标签页的修改。
- 本地练习占用空间按存储键与原始 JSON 的 UTF-16 代码单元估算，显示 B / KiB / MiB；不是浏览器实际磁盘占用或剩余配额，不包含其他站点数据。清空后为 0 B。

自定义题目列表提供新建、开始练习、编辑和删除；后三项集中在右侧操作区，统一使用左侧图标。本地与账号均复用现有编辑器修改名称和节奏，保存覆盖原 ID，不切换模式、不生成副本。保存修改后留在编辑页，顶部浮层提示“修改已保存”，3 秒后消失，不占布局空间；连续保存重新计时。继续修改后离开仍会提醒，失败保留草稿并显示原因。新建保存返回列表并短暂提示“练习已创建”，刷新或历史返回不重播；列表不保留“已保存”标记。删除须确认且不可恢复，失败保留列表；账号页删除至空页时退回前一页。

账号练习 API 位于 `src/api/customExercises.ts`。页面按每页 50 条读取摘要，进入练习后再获取完整题目。账号请求失败不回退本地、不自动重试；登录状态未知时暂停读取和保存。身份切换会卸载旧练习、取消旧读取；编辑草稿按原身份保留，不带入另一身份。

本地题目沿用 `/custom/:mode/:exerciseId`，账号题目使用 `/custom/:mode/account/:exerciseId`；地址明确来源，不因登录状态改变而改读另一份题目。

## 代码导航

侧栏底部提供「设置／关于」辅助入口。「关于」页面位于 `/about`，仅提供 GitHub 仓库链接与联系邮箱。桌面折叠按钮位于侧栏和正文的分界线上，与首页 Logo 独立，继续记住折叠偏好；移动端沿用菜单抽屉。

首页 `/` 提供三个平级入口：预设练习 `/preset`、随机练习 `/random`、自定义练习 `/custom`。
`navigation/SiteNavigation.tsx` 统一提供首页、三类练习、练习记录及设置入口，当前页和所属栏目通过 `aria-current` 与主题选中样式标识。桌面侧栏的折叠偏好保存在本地，图标模式保留可访问名称；存储不可用时本次会话仍可折叠。移动端通过菜单按钮打开模态抽屉，支持关闭按钮、Esc、点击遮罩和选择链接关闭；打开期间锁定页面滚动，路由变化或切回桌面也会关闭。

```text
src/
├── main.tsx、App.tsx、App.css、index.css  # 入口、路由与全局样式
├── navigation/                        # 全站导航、历史恢复、模块预加载与加载占位
├── brand/                             # 节拍器品牌标记
├── pages/                              # 路由页面与题目来源入口
├── api/                                # 登录与账号练习的 HTTP 请求
├── auth/                               # 共享登录状态
├── settings/                           # 外观、击拍精度的偏好与本地保存
├── practice/                           # 共用工作区、练习交互和编辑器
├── practice-records/                   # 游客练习记录、计数规则与本地存储
├── rhythm/                             # 节奏模型与解析、计时判定与音频
│   └── notation/                       # 谱面绘制与反馈定位
└── exercises/                          # 预设题库、随机生成与自定义存储
```

测试位于 [tests/](tests/)，音频等静态资源位于 [public/](public/)。函数与组件的具体约定见对应代码。

## 游客练习记录

- 按来源、题目 ID、模式和节奏内容版本累计，不按页面访问分记录。预设和自定义再次进入沿用记录；改名不拆分，修改节奏分别记录，恢复旧内容会继续旧版本。随机每次成功生成分配独立编号，相同谱面也不合并；未练习不建空记录。
- 击拍：仅自然结束后追加尝试，保存完成时间、速度、判定精度与命中／漏拍／误敲结果；试听和手动停止不计入。迟到输入修正同一尝试，不额外追加。
- 听写：一道题下保留多次尝试，一份空白作答对应一次尝试；首次有效听题、验证或查看答案才建立。每次保存开始时间、完成时间（未完成为 null）、是否查看答案及各小节的听题次数、验证次数、判定（未验证／正确／错误），不再跨尝试累计小节数据。
- 整题播放给本次所有小节加一次，仅播放当前小节只给该小节加一次；成功启动即计数，中途停止不撤回，播放自己的答案不计入。未改答案重复验证不重复计数；修改小节清除该小节判定，保留本次次数。仅编辑不创建尝试。
- 全部小节验证正确时记录完成时间并冻结该次记录，作答只读；之后播放或查看答案属于复盘，不改次数或查看答案标记。未全部正确则保留为未完成，验证错误不结束尝试。
- 不提供“重新练习”或“再做一次”按钮。站内后退恢复原草稿时延续原尝试；从列表重新进入或刷新从空白开始，首次有效操作后追加下一次尝试。
- 题目保留首次和最近练习时间，列表按最近时间倒序；听写每次尝试只含开始、完成时间，不含最近操作时间；击拍每次尝试显示完成时间。不统计时长。仅打开、编辑或重复验证不更新时间。
- `/records` 列表仅展示题目名称、来源和模式，右侧并列「查看详情／删除」操作；查看详情打开右侧抽屉。关闭按钮、Escape 或点击遮罩可关闭，保留列表筛选、已加载数量和滚动位置。窄屏抽屉占满屏幕。记录不上传、不跨设备同步，清理网站数据会丢失。
- 写入失败保留待保存行为并提供重试，站内返回也可重试；成功后移除队列，不保留操作日志。刷新前应先完成重试。旧试验格式不会自动迁移或覆盖，需在本地数据设置中自行确认清空；不会影响自定义题库。
- 详情分「尝试记录／题目预览」两种视图。两种模式均以表格每行展示一次尝试，最近优先且保留原编号；听写只在行内展开小节明细。预览为只读谱面，不显示小节选择控件。删除位于列表行右侧，与详情入口分开，需确认。日期紧凑显示，悬停可查看完整时间。
- 本地数据以「自定义题库」和「练习记录」两组紧凑摘要展示，清空按钮对应归组，窄屏排到摘要下方。清空范围在确认弹窗中说明，成功使用可关闭 Toast；两类数据互不删除。

## 本地开发与联调

先按 [后端说明](../backend/README.md#本地运行) 在一个终端启动后端，再从仓库根目录另开终端运行：

```sh
cd frontend
npm ci
npm run dev
```

访问 Vite 输出的地址，默认 `http://localhost:5173`。[vite.config.ts](vite.config.ts) 将 `/api` 和 `/api/` 下的请求转发到 `http://127.0.0.1:8000`，保留路径。前端始终请求同源 `/api/...`，不要硬编码后端地址或额外开放凭证跨域。

在前端页面的浏览器控制台验证完整链路：

```js
const response = await fetch('/api/health');
console.log(response.status, await response.json());
// 200 { status: 'ok' }
```

直接访问后端健康检查不能验证 Vite 代理。代理失败时先确认后端已启动；8000 端口被占用时先检查现有进程，不重复启动。修改代理配置后重启 Vite。登录配置、Origin 与接口约定统一见 [后端说明](../backend/README.md#本地开启账号功能)。

### 页面验收

1. 账号关闭时，设置 → 账号显示关闭说明；击拍和听写均可新建、保存并刷新读取本地题目。
2. 账号开启后，游客仍可使用本地题库。在设置 → 账号登录，成功后原位显示账号状态，刷新仍保持登录；退出后原位恢复登录表单。
3. 登录后保存题目，返回账号列表并刷新，确认可进入对应模式；退出后显示原本地题库，不自动迁移或合并。
4. 账号详情 `/custom/:mode/account/:exerciseId` 不得读取本地同 ID 题目；其他账号、不存在或模式不匹配的题目不应启动训练。切换身份后不能残留旧账号内容或被旧请求覆盖。
5. 身份查询故障应暂停自定义练习读取和保存；账号保存失败保留草稿，不回退本地。响应丢失时先检查账号列表，避免重复提交。退出失败不能假定已经退出。

手动发送验证码会产生真实短信请求；费用与测试配置注意事项见后端说明。请求封装位于 [src/api/customExercises.ts](src/api/customExercises.ts)：错误状态 0 表示网络失败，502 也用于非法响应，取消读取保留 `AbortError`。

## 部署

Docker 启动见 [项目 README](../README.md#快速启动)，仓库中的 [Nginx 配置](nginx.conf) 已处理静态文件、独立题库和 API 转发。手动部署时需注意：

- 发布 `dist/` 中的构建产物；Vite 的本地开发代理不会随构建产物部署。
- React Router 使用普通路径，页面请求需回退到 `index.html`，保证直接打开或刷新 `/preset/:questionId` 等地址可以正常显示。
- `/api` 请求应交给后端，静态资源按实际文件处理，不能被页面回退规则吞掉。
- 客户端显示“未找到页面”不等于服务器返回 HTTP 404，状态码策略需由部署环境配置。
