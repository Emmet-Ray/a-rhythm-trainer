# 节奏训练前端

使用 React、TypeScript、Vite 和 React Router，谱面由 VexFlow 绘制。

## 常见节奏型输入

自定义新建页沿用练习工作区：顶部提供试听、名称和保存，主区提供谱面及编辑工具，设置侧栏提供节拍器、速度和小节数量。窄屏设置移至谱面上方，工具栏自然换行；保存错误在顶部显示，超拍提示仍位于编辑工具附近。小节删除确认、草稿恢复及保存流程保持原有规则。

编辑器提供二平均、四平均、前八后十六、前十六后八、小附点、反小附点、小切分、大附点、反大附点、大切分十种快捷输入。后三种各占两拍，其余各占一拍（以四分音符为一拍）。基础工具与常见节奏型常驻并排，空间不足时上下排列；共用附点、删除末尾及清空操作。快捷输入一次追加整组普通音符，超拍时整组拒绝，不改变数据格式，添加后仍可逐音符编辑；三连音继续按原有分组规则处理。

## 页面返回恢复

练习详情共用紧凑题头：预设和自定义显示返回入口及原题名，随机练习仅显示返回入口。题头不重复主题、模式或存储来源，宽屏一行优先，长题名自然换行；返回仍使用原有历史恢复机制。

全站新导航默认回到顶部，浏览器后退／前进恢复对应历史记录的页面滚动位置。预设列表保留页面级训练模式和当前主题，设置页保留分类，自定义账号题库保留分页；同一 URL 的多次访问分别保存。页面内“返回”链接优先回到当前应用会话中已有的目标历史记录，没有已知来源时按普通链接打开目标；修饰键和新标签打开仍保留链接原生行为。

预设列表在右栏主题标题旁统一选择击拍或听写，长标题或窄屏时自然换行。桌面右栏标题与模式固定，下方题目列表和左侧主题导航各自滚动，不带动页头或另一栏。切换主题或模式时题目列表归零，返回列表时恢复两栏滚动位置。窄屏改用主题选择框和普通页面滚动。切换主题不改变训练模式，无对应题目时显示空状态，不展示未开放模式。

`navigation/PageVisits` 只保存浏览现场，不缓存服务器数据或组件。`useVisitState` 声明需要恢复的 UI 字段，路由内容按历史记录 key 挂载；新增异步页面的加载占位须标记 `data-navigation-pending`，内容就绪后才恢复滚动。用户主动滚动会取消待执行的恢复，避免加载结束后抢回视野。账号题库重新获取原分页数据，空页退到最近有效页；分页和滚动按身份隔离。

快照仅保存在当前应用实例内，刷新或关闭页面后不保留。自定义新建草稿也按历史访问保存名称、小节内容、选中小节及生效的 BPM／节拍器开关，身份和模式隔离；返回原记录恢复，重新点击“新建”创建空草稿。保存失败保留，确认成功后仅清除提交版本，不清除离开后继续编辑的新版本；不自动保存到题库。不恢复谱面内部滚动。离开练习仍卸载播放器并停止音频，不恢复播放、预备拍或正在运行的轮次；主题与击拍精度继续使用已有偏好存储。

随机练习按历史记录保留生成配置和当前题目，返回不重新生成，已有题目时不自动展开设置抽屉。听写三种来源共用 `PracticeWorkspace` 的作答快照，恢复答案、选中小节、逐小节验证结果、播放范围及生效设置。`DictationState` 以题目内容和题目编号共同校验绑定：换题即使内容相同也清空作答，同编号自定义题内容变化后也不沿用旧答案；自定义来源按账号／本地身份隔离。听写组件只接收作答状态，不直接访问路由存储。结果遮罩、参考答案显示状态、音频与预备拍不恢复；新访问从默认状态开始。

回归检查：切换页面级模式及主题后进入题目，分别用页面返回和浏览器后退恢复；前进后再次返回；同地址新访问使用默认状态；设置分类返回恢复；账号题库第 2 页及延迟响应、删除后空页回退；直接打开题目时返回入口可用。

## 练习交互

听写“查看答案”在原谱面窗口切换为只读参考谱面，不再在页面底部展开。参考模式明确标注“参考答案”，编辑工具和验证按钮不可操作但保留占位；点击“返回作答”恢复原草稿、选中小节、验证状态及横向滚动位置。参考谱面与草稿分别渲染，答案不会传入草稿编辑回调，查看答案不会触发通过结果；播放操作仍保留原有含义。

听写顶部的“仅播放当前小节”同时控制题目和我的答案：默认不勾选，播放整题；勾选后显示当前小节编号，播放所选小节。切换范围仍停止当前播放，保留草稿与验证结果。

作答、编辑与参考答案共用单行谱面：宽屏双小节利用可用宽度，长题和窄屏在谱面窗口内左右滚动，编辑工具不随横向滚动移动。同宽窗口下，小节宽度、符号倍率和谱面高度不随小节数量变化；单小节左对齐，右侧留白。小节宽度按十六分音符容量预留，增删音符不改变小节边界或重置滚动位置；空小节不补休止符，编号使用 VexFlow 内置小节号。

谱面上方的小节导航列出全部小节并突出当前项。点击数字同步编辑位置，仅在目标未完整可见时横向定位；点击谱面也同步导航，手动滚动不改变选中小节。返回恢复草稿时，等待窗口宽度就绪后将选中小节带入视野一次（窄屏对齐小节起点），不恢复精确的历史横向位置；随后编辑、手动滚动或调整窗口尺寸不自动拉回。参考答案使用独立的浏览导航，不影响作答的选择及滚动位置；两种模式保留相同的导航行高度。

当前支持击拍练习、节奏听写，以及预设、随机和自定义三种题目来源；几何游戏未开放。已接入短信登录、会话恢复与退出，以及账号自定义练习的保存、列表和练习读取。

## 练习控件

预设与自定义题目区最大宽度为 720px，在公共框架内左对齐；题目使用最小高度 64px 的整行链接与淡分隔线，悬停显示浅色底，键盘聚焦显示轮廓。预设模式切换位于主题标题下方，自定义“新建练习”位于题目区上方并右对齐；窄屏随可用宽度收缩，长题名换行。首页和模式入口卡片不受影响。

全站共用白色通栏页头、浅色页面背景、1440px 最大内容宽度和响应式左右留白；页头位置不随路由、练习模式或加载状态改变。功能页标题、返回栏与内容外边界对齐页头，较窄的列表与设置内容在公共框架内左对齐；预设与设置页共用侧栏宽度和列间距，窄屏改为上下布局。首页入口与登录表单保留居中布局。听写与自定义编辑使用白色底面，内部操作顺序不变。

击拍工作区顶部整行放击拍／试听按钮，下方分为左侧谱面与反馈、右侧节拍器与 BPM 设置栏。窄屏时顶部工具栏换行，下方设置与谱面上下排列，不重建训练或重置设置。谱面按可用宽度适度放大（最高 1.6 倍），排版和反馈共用缩放坐标。预设、随机和自定义击拍共用。

听写与击拍共用 `PracticeFrame` 布局：顶部通栏左侧放“播放题目／播放我的答案”和播放范围，右侧保留随机练习的生成操作；下方左侧为作答／参考谱面窗口、编辑工具和验证操作，右侧放同一套节拍器与 BPM。窄屏自动换行并上下排列。框架不持有播放或作答状态，调速／切换范围仍只重建播放器，保留草稿与验证结果，换题才重置作答；自定义新建编辑页保持原布局。

随机击拍与听写首次进入即按默认范围生成两小节题目，不自动播放、不自动打开设置；同一历史记录返回时恢复原题及配置，不重复生成。生成配置放在右侧抽屉，窄屏占满宽度。标题、小节数和练习范围标题固定在顶部，空选或生成失败的提示紧跟范围标题，不随选项滚动。范围分为音符、休止符、节奏型三个分组，每项独立勾选并显示真实记谱图形；音符与休止符宽屏双列、窄屏单列，节奏型单列，整个选项区独立滚动。抽屉不提供生成或提交按钮，支持关闭按钮、Esc 和遮罩关闭；关闭保留当前历史记录内的材料、小节数选择，不立即换题，也不保存到浏览器。修改配置后仅通过工作区“换一题”应用新配置出题，失败打开抽屉提示；范围为空时禁用生成。音频准备及播放期间禁用生成和设置入口，换题保留 BPM 与节拍器设置。预设和自定义练习不显示这些入口。

随机范围表示允许使用的材料，不保证每题覆盖全部选项。默认选中全音符、二分音符和四分音符；支持单独音符、附点四分／八分音符、五种休止符及十一种节奏型（含小三连）。节奏型整组生成，无需勾选其基础音符；普通材料按自身网格放置，附点四分／八分音符与一拍节奏型从拍头开始，两拍节奏型从第 1、3 拍开始。生成器只使用勾选材料，无法填满 4/4 小节时提示增加其他材料，不自动补入未选音符或休止符。编辑器快捷输入和随机组合复用 `rhythm/RhythmPatterns.ts` 定义，显示预览与生成内容保持一致。

击拍谱面使用 VexFlow 内置小节序号，编号位于对应小节左上方；滚动窗口根据屏幕高度容纳完整的一至两行。击拍／试听按音频时钟定位的事件（含休止符）跟随谱行，两行窗口保留当前行与下一行；滚动采用按行切换，不连续移动音符，也不重建谱面或改变判定。滚轮、触摸、滚动条或方向／翻页键操作会暂停本轮跟随，可点击“继续跟随”恢复。停止或结束后保留位置供复盘，新一轮回到首行并恢复跟随；听写和编辑谱面不受影响。

音频加载时仅对应的开始／试听按钮显示“准备中…”。预备拍用半透明深色遮罩压暗谱面可视窗口，中央显示倒数（默认 4、3、2、1），读取现有音频时钟，点击不关闭，正式开始立即消失，不增加额外拍。击拍过程只保留音符下方的判定标记，不再重复显示文字反馈。自然结束后相同遮罩中央显示“通过／未通过”，点击遮罩内任意位置（含结果文字）即可关闭；也可聚焦关闭按钮后用 Enter、空格或 Esc 关闭。关闭后保留谱面标记，重新开始或调整配置会清除旧结果；试听结束和手动停止不显示结果。遮罩不占布局空间、不随谱面滚动，不覆盖顶部操作栏和节拍器；音频错误在顶部操作栏提示。

听写复用击拍的 `PracticeCue` 遮罩内容：播放题目和播放答案的预备拍由原有音频时钟倒数，正式播放、停止、调速、切换范围或小节时清除，不再显示按钮旁的播放状态文字。单小节验证在对应谱面左上方显示“✓ 正确／× 有错误”，随小节横向滚动；小节导航同步显示红叉或绿勾，紫色仍只表示选中。修改该小节后同时清除两处结果，其他小节不受影响；未验证不显示标记。全部小节验证正确才显示可关闭的“通过”遮罩。查看参考答案和播放结束不触发通过，重新播放会关闭旧结果。草稿编辑器与谱面只接受验证状态并统一呈现，不负责判定。

编辑器的“清空当前小节”直接清除当前小节全部内容，不弹确认框；保留小节及选中位置，不影响其他小节。空小节时禁用，清空后移除编辑提示；听写同时重置该小节验证结果，不修改标准答案或已保存的练习。

听写作答与自定义练习共用节奏编辑器：音符、休止符、小三连和附点使用音乐符号按钮，悬停可查看名称，也保留键盘操作和无障碍名称。“删除末尾”保留文字。图形沿用谱面的记谱规则，全／二分休止符带短参考线；工具栏在窄屏自动换行。添加、附点和删除仍作用于当前小节末尾，不改变容量限制。

练习设置中的机械节拍器可点击开启／关闭，与 BPM 控件放在一起。开启后随击拍、试听、听写及自定义试听的音频时钟左右摆动；空闲时不独立发声。中途关闭、停止或调速后摆杆归中，重新开启接上当前拍位；关闭时预备拍声音仍保留。系统启用“减少动态效果”时不摆动，声音和开关照常工作。

练习页面共用 BPM 调速控件（40–240，默认 60）：拖动乌龟／兔子之间的滑块，松手后生效；也可直接输入，失焦或回车生效。回车确认合法数值后退出输入焦点（未修改也退出），空值、越界或非整数则保留焦点并提示。滑块支持键盘方向键和 Home／End。速度真正改变才停止当前练习／播放，不自动重启；击拍谱面保留，只清除本轮反馈。移出轨道松手仍提交，控件失焦或失去指针捕获不回退；真正取消操作（Escape、指针取消或窗口失焦）恢复原速度。非法值保留原速度并提示。听写和自定义编辑草稿不会因改速丢失，速度本身不持久保存。

## 数据保存

- 未登录时，自定义练习保存于当前站点的 `localStorage`；已登录时保存到后端，列表只显示当前账号的题目。
- 本地题库与账号题库独立，不自动迁移或合并。更换浏览器、域名或端口不会共享本地数据，清除网站数据会丢失本地练习。
- 未保存的编辑草稿只在当前应用会话内保留，返回原编辑记录可恢复；刷新或关闭页面后丢失。身份尚未确认时先等待，不把账号草稿作为本地草稿打开。
- 练习结果尚未持久保存，刷新或重新进入页面不会恢复旧成绩。
- 登录凭证由后端设置为 HttpOnly Cookie，前端不读取或写入 localStorage；登录、退出不会迁移或删除本地练习。
- 登录表单的手机号与验证码格式错误紧跟对应输入框，并关联辅助说明、标记错误与聚焦；编辑后清除旧错误。发送成功后聚焦验证码框，网络及服务错误保留在提交按钮上方的紧凑反馈区，长提示自然换行。发送冷却和认证流程不变。
- 设置页 `/settings` 提供紫色、蓝色和青绿色主题，选择后立即生效；偏好独立保存在当前浏览器，不要求登录、不与账号同步。恢复默认只重置配色，不删除本地练习。存储失败时仍可临时切换，并显示提示。
- 设置页提供外观、本地数据、声音、击拍精度四个分类：桌面左侧导航、右侧内容，窄屏导航移到上方，手机两列展示全部分类。主题与精度选项按可用宽度自然换行，本地统计限宽；精度说明明确从下一轮生效，清空按钮前说明数据范围，反馈紧跟操作。默认展示外观，分类切换由页面状态管理，不增加子路由。声音入口标注未开放，暂不提供音色设置。
- 击拍精度提供宽松、标准（默认）、严格三档，完美／命中容差分别为 80／200ms、50／150ms、30／100ms。三种来源的击拍练习共用，开始一轮时固定参数，不改变当前轮次或迟到输入重算，也不影响试听和听写。偏好只保存在当前浏览器，恢复默认只重置击拍精度；保存失败仍供当前页面会话的下一轮使用并提示，刷新后可能恢复标准。与外观偏好一样，暂不自动同步其他已打开标签页，刷新后读取最新保存值。
- 本地数据展示练习总数及击拍、听写数量，不提供练习入口。清空前使用浏览器确认框，确认后仅删除本地练习，不影响主题、登录状态或账号题库。空题库禁用清空；读取失败不显示零，可重试或确认清空损坏数据；删除失败显示错误。每次进入该分类重新读取，暂不实时同步其他标签页的修改。
- 本地练习占用空间按存储键与原始 JSON 的 UTF-16 代码单元估算，显示 B / KiB / MiB；不是浏览器实际磁盘占用或剩余配额，不包含其他站点数据。清空后为 0 B。

自定义题目列表使用紧凑页头，提供返回、模式标题和新建入口；本地与账号题目均只展示题名和开始练习入口。空列表引导新建，保存返回时在对应题目上显示淡紫底和“已保存”，不强制滚动；暂不展示未开放的编辑按钮。

账号练习 API 位于 `src/api/customExercises.ts`。页面按每页 50 条读取摘要，进入练习后再获取完整题目。账号请求失败不回退本地、不自动重试；登录状态未知时暂停读取和保存。身份切换会卸载旧练习、取消旧读取；编辑草稿按原身份保留，不带入另一身份。

本地题目沿用 `/custom/:mode/:exerciseId`，账号题目使用 `/custom/:mode/account/:exerciseId`；地址明确来源，不因登录状态改变而改读另一份题目。

## 代码导航

首页 `/` 提供三个平级入口：预设练习 `/preset`、随机练习 `/random`、自定义练习 `/custom`。
公共页头的“练习”下拉菜单提供相同入口，在题目页也标识所属栏目；鼠标悬停展开、移入面板保持展开、离开菜单区域收起，悬停展开后点击触发器不会反向关闭。触屏与键盘保留原生展开、收起操作。选择链接、点击外部、焦点移出或按 Esc 也会收起菜单。

```text
src/
├── main.tsx、App.tsx、App.css、index.css  # 入口、路由与全局样式
├── pages/                              # 路由页面与题目来源入口
├── api/                                # 登录与账号练习的 HTTP 请求
├── auth/                               # 共享登录状态
├── settings/                           # 外观、击拍精度的偏好与本地保存
├── practice/                           # 共用工作区、练习交互和编辑器
├── rhythm/                             # 节奏模型与解析、计时判定与音频
│   └── notation/                       # 谱面绘制与反馈定位
└── exercises/                          # 预设题库、随机生成与自定义存储
```

测试位于 [tests/](tests/)，音频等静态资源位于 [public/](public/)。函数与组件的具体约定见对应代码。

## 联调与部署

本地 Vite 已将 `/api` 请求代理到 `http://127.0.0.1:8000`；启动后端和验证代理的方法见 [联调说明](../联调.md)。

生产环境需要单独配置：

- 发布 `dist/` 中的构建产物；Vite 的本地开发代理不会随构建产物部署。
- React Router 使用普通路径，页面请求需回退到 `index.html`，保证直接打开或刷新 `/preset/:questionId` 等地址可以正常显示。
- `/api` 请求应交给后端，静态资源按实际文件处理，不能被页面回退规则吞掉。
- 客户端显示“未找到页面”不等于服务器返回 HTTP 404，状态码策略需由部署环境配置。
