# 节奏训练前端

使用 React、TypeScript、Vite 和 React Router，谱面由 VexFlow 绘制。

当前支持击拍练习、节奏听写，以及预设、随机和自定义三种题目来源；几何游戏未开放。已接入短信登录、会话恢复与退出，以及账号自定义练习的保存、列表和练习读取。

## 本地运行

准备好 Node.js 和 npm，从仓库根目录执行：

```sh
cd frontend
npm ci
npm run dev
```

打开终端显示的本地地址。以下命令均从 `frontend/` 执行。

## 检查与构建

```sh
npm test
npm run lint
npm run build
```

测试覆盖节奏计时与判定、音频调度、谱面布局、题库、随机生成、编辑器和自定义存储等逻辑。实际声音效果、键盘交互、页面导航和响应式布局仍需在浏览器中验证。

构建产物位于 `dist/`。构建后可在本地预览：

```sh
npm run preview
```

预览命令用于检查构建产物，不作为生产服务器。

## 数据保存

- 未登录时，自定义练习保存于当前站点的 `localStorage`；已登录时保存到后端，列表只显示当前账号的题目。
- 本地题库与账号题库独立，不自动迁移或合并。更换浏览器、域名或端口不会共享本地数据，清除网站数据会丢失本地练习。
- 未保存的编辑草稿仅在内存中，离开页面或刷新后会丢失。
- 练习结果尚未持久保存，刷新或重新进入页面不会恢复旧成绩。
- 登录凭证由后端设置为 HttpOnly Cookie，前端不读取或写入 localStorage；登录、退出不会迁移或删除本地练习。

账号练习 API 位于 `src/api/customExercises.ts`。页面按每页 50 条读取摘要，进入练习后再获取完整题目。账号请求失败不回退本地、不自动重试；登录状态未知时暂停读取和保存。身份切换会卸载旧练习、取消旧读取，编辑草稿保留。

本地题目沿用 `/custom/:mode/:exerciseId`，账号题目使用 `/custom/:mode/account/:exerciseId`；地址明确来源，不因登录状态改变而改读另一份题目。

## 代码导航

首页 `/` 提供三个平级入口：预设练习 `/preset`、随机练习 `/random`、自定义练习 `/custom`。
公共页头的“练习”下拉菜单提供相同入口，在题目页也标识所属栏目；鼠标悬停展开、离开菜单区域收起，触屏保留点击展开。支持键盘操作，选择链接、点击外部或按 Esc 也会收起菜单。

```text
src/
├── main.tsx、App.tsx、App.css、index.css  # 入口、路由与全局样式
├── pages/                              # 路由页面与题目来源入口
├── api/                                # 登录与账号练习的 HTTP 请求
├── auth/                               # 共享登录状态
├── practice/                           # 共用工作区、练习交互和编辑器
├── rhythm/                             # 节奏模型与解析、计时判定与音频
│   └── notation/                       # 谱面绘制与反馈定位
└── exercises/                          # 预设题库、随机生成与自定义存储
```

测试位于 [tests/](tests/)，音频等静态资源位于 [public/](public/)。函数与组件的具体约定见对应代码。

## 联调与部署

本地 Vite 已将 `/api` 请求代理到 `http://127.0.0.1:8000`；启动后端和验证代理的方法见 [联调说明](../联调.md)。

生产环境需要单独配置：

- 发布 `dist/` 中的构建产物；Vite 的本地开发代理不会随构建产物部署。
- React Router 使用普通路径，页面请求需回退到 `index.html`，保证直接打开或刷新 `/preset/:questionId` 等地址可以正常显示。
- `/api` 请求应交给后端，静态资源按实际文件处理，不能被页面回退规则吞掉。
- 客户端显示“未找到页面”不等于服务器返回 HTTP 404，状态码策略需由部署环境配置。
