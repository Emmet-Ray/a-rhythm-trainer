# 节奏训练前端

使用 React、TypeScript、Vite 和 React Router，谱面由 VexFlow 绘制。

当前支持击拍练习、节奏听写，以及预设、随机和自定义三种题目来源；几何游戏未开放。前端尚未接入账号登录与云端练习存储，现有练习功能可独立运行。

## 本地运行

准备好 Node.js 和 npm，从仓库根目录执行：

```sh
cd frontend
npm ci
npm run dev
```

打开终端显示的本地地址。以下命令均从 `frontend/` 执行。

## 检查与构建

```sh
npm test
npm run lint
npm run build
```

测试覆盖节奏计时与判定、音频调度、谱面布局、题库、随机生成、编辑器和自定义存储等逻辑。实际声音效果、键盘交互、页面导航和响应式布局仍需在浏览器中验证。

构建产物位于 `dist/`。构建后可在本地预览：

```sh
npm run preview
```

预览命令用于检查构建产物，不作为生产服务器。

## 数据保存

- 自定义练习目前保存于当前浏览器、当前站点来源的 `localStorage`，尚无账号隔离、云同步或备份。
- 更换浏览器、域名或端口不会自动共享这些数据；清除网站数据会丢失已保存练习。
- 未保存的编辑草稿仅在内存中，离开页面或刷新后会丢失。
- 练习结果尚未持久保存，刷新或重新进入页面不会恢复旧成绩。

## 代码导航

```text
src/
├── main.tsx、App.tsx、App.css、index.css  # 入口、路由与全局样式
├── pages/                              # 路由页面与题目来源入口
├── practice/                           # 共用工作区、练习交互和编辑器
├── rhythm/                             # 节奏模型、计时判定与音频
│   └── notation/                       # 谱面绘制与反馈定位
└── exercises/                          # 预设题库、随机生成与自定义存储
```

测试位于 [tests/](tests/)，音频等静态资源位于 [public/](public/)。函数与组件的具体约定见对应代码。

## 联调与部署

本地 Vite 已将 `/api` 请求代理到 `http://127.0.0.1:8000`；启动后端和验证代理的方法见 [联调说明](../联调.md)。

生产环境需要单独配置：

- 发布 `dist/` 中的构建产物；Vite 的本地开发代理不会随构建产物部署。
- React Router 使用普通路径，页面请求需回退到 `index.html`，保证直接打开或刷新 `/practice/:questionId` 等地址可以正常显示。
- `/api` 请求应交给后端，静态资源按实际文件处理，不能被页面回退规则吞掉。
- 客户端显示“未找到页面”不等于服务器返回 HTTP 404，状态码策略需由部署环境配置。
