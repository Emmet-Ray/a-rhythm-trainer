# 节奏训练前端

使用 React、TypeScript、Vite 和 React Router，谱面由 VexFlow 绘制。

## AI 助手

未配置 API Key 或配置检查失败时，首页显示独立错误提示与“重新检查配置”，隐藏聊天界面和其他页面的助手入口。

模型配置可用时，首页直接展示助手：未开始对话时展示标题与紧凑输入框；传统练习入口保留在站点导航。输入框内的「练习」菜单提供击拍／听写模板，选择后填入草稿，不自动发送。单行输入与操作同排，内容换行后展开为文字区与底部操作区。开始对话后展示消息流与练习卡片。首页页头、消息和输入框共用居中阅读列，字号比侧栏更舒展。其他页面通过右下角「AI 助手」打开侧栏。两种布局共用一个持续挂载的对话组件，切换不清空消息、未发送文字、正在生成的回答及卡片 BPM／小节选择。刷新后恢复当前浏览器上次打开的实例对话；浏览器只保存当前会话 ID，消息与卡片 BPM／答案查看状态由后端 JSONL 保存。页头「历史对话」通过按钮下方浮层切换和删除，保留当前消息与输入框；点击外部或 Esc 关闭。生成期间也可浏览历史；切换到其他对话会停止当前生成，保留已保存内容。刷新时统一等待配置和会话恢复，完成后才显示欢迎语或历史内容；耗时较长时显示轻量占位。历史对话支持打开和删除，开始新对话不会删除旧对话。未发送草稿和卡片小节选择不跨刷新保存。

宽度达到 1100px 时，助手与页面并排；更窄时使用全屏模态覆盖层，隔离背景焦点并锁住背景滚动，Esc 或关闭按钮返回原页面。首页不显示重复的悬浮入口和关闭按钮。从卡片点击「开始击拍／开始听写」在当前页面上方打开训练覆盖层，不切换路由或移动对话；桌面居中展示，700px 及以下全屏。打开时停止当前试听或后台训练，但不会自动启动覆盖层训练；关闭按钮或 Esc 退出，停止训练音频并恢复卡片焦点、背景滚动与原对话。遮罩点击不关闭面板。训练快捷键仅在最上层训练面板生效。其他页面间导航保留助手开关；返回首页展开原对话。

输入框随内容自动增高，提交后立即清空；确认输入未写入会话时恢复草稿，结果不确定时先同步，不自动重发。支持流式回答、停止生成、新对话及消息时间；助手文字使用基础 Markdown 展示。首次发送创建后端会话，之后只提交本次 `text` 和 `page_context`。首页、自定义编辑器及预设、随机、自定义、AI 练习工作区提供当前快照；未接入的页面发送 `null`，不会沿用上一页资料。

生成结果从正式会话的工具记录中解析为卡片，可预览、调速试听并进入对应训练。听写默认隐藏谱面，查看状态会传入训练记录。在自定义编辑页可以「放入编辑器」，填入名称和节奏，继续编辑后手动保存。操作按钮不再次请求模型。流式消息由 AI SDK UI 的 `useChat` 与 `DefaultChatTransport` 管理；结束、失败或停止后查询后端会话校准正式历史；同步失败时阻止继续发送，失效时提示新建。

助手默认综合当前题目的本次多轮表现，关注最近仍存在的问题，自动参考同来源、同编号、同谱面版本的历史。页面快照描述当前工作区；练习活动由记录入口收集，跨页面保留，随下一条消息发送。关闭覆盖层后最近产生结果的题目仍是默认讨论对象，不会被底层页面覆盖。新击拍记录保存实际速度、判定窗口、逐音符早晚偏差及中断标记；旧记录只能比较汇总。每个范围最多携带最近 20 轮，最近 3 轮提供至多 64 处问题位置，容量不足时减少较早轮次。历史存储不可用时仍可分析本次结果，不把读取失败视为没有历史。听写未查看答案时只发送作答和验证事实，不附带标准谱面；旧听写记录未记录速度，不能直接假定条件相同；新记录累计不同速度和节拍器设置下的播放次数、最新作答和验证进展。针对性出题复用现有生成工具，不自动替换正在练习的题目。

助手生成回复时允许继续编辑草稿、使用练习模板及操作已有练习卡片；本轮结束后再发送，生成期间 Enter 换行，Shift+Enter 始终换行。停止或发送失败不覆盖已经写好的下一条草稿，不自动排队发送。工具结果通过标准 `tool-output-available` 事件即时推送，卡片先出现，后续建议继续流式输出；结束同步不重复插入或重新挂载卡片。

助手回复（含流式临时内容）使用 `react-markdown` 渲染基础 CommonMark：段落、标题、强调、列表、引用、链接及代码；用户消息保留原文。标题使用紧凑层级，代码块可横向滚动，不执行原始 HTML、不加载模型提供的图片。本版未增加表格、公式或代码高亮。`tests/browser/assistant-ux.js` 模拟可暂停 SSE，验证生成期间输入、模板、练习、停止与失败后的草稿保留。

页面上下文已覆盖首页、自定义编辑器、所有练习工作区、预设目录与同题组导航、随机入口与生成设置、自定义题目列表、记录列表与详情、设置、关于及未找到页面。目录最多附带前 50 条摘要并注明总量或截断；自定义题目列表仅包含已加载页，总量未知时为 null，不请求全库。预设完成状态匹配本地同题同谱面版本记录，不可读取时明确标记。

记录页统计沿用页面的时间／模式筛选；列表只附带当前页，详情独立说明“全部历史”及当前明细分页。听写详情未公开答案时不发送标准谱面，切到题目预览后才提供。随机生成设置表示下一次换题的条件，不宣称已应用到当前题目。设置页只提供公开偏好，不传模型凭证；声音设置明确标记未开放。

`useAssistantPageSection()` 用于当前展开的记录详情或设置子面板，补充基础页面字段，卸载时只移除自己的数据；页面快照随消息读取，不产生练习活动。`tests/browser/page-context.js` 使用模拟模型检查各页面实际发送的快照、筛选与设置更新、子面板清理和听写答案隐藏。

上下文整理分工：`assistant/practiceContextSummary.ts` 负责题目、轮次和同题历史摘要；`practice/PracticeWorkspace.tsx` 补充当前速度、播放状态和选中小节等页面信息；`assistant/practiceActivity.ts` 管理活动收集、合并与发送确认，只携带记录中的实际设置和结果。

练习活动从首次发送或恢复助手对话时启用，新对话清空；尚未发送的活动批次不跨刷新保存，已发送上下文随历史保留，恢复后沿用最近的练习引用。只在练习记录产生/更新时累计，不记录进入退出或普通点击。击拍按轮次、听写按一次作答合并；本地保存失败不影响收集。批次编号随消息保存，前端确认后端接收后才标记已发送，失败保留，发送期间更新留给下一批。最多保留最近 100 个尝试更新，单批最多 5 道题，并控制消息体积；被省略的范围会在上下文中说明。再次提问没有新结果时只带最近练习引用，不重复上传活动。当前快照和相关同题历史仍可提供已有成绩，无需增加前端查询工具。

`tests/browser/practice-activity.js` 验证预设页面侧栏出题、覆盖层击拍/听写、关闭后分析，以及发送失败、本地保存失败和听写累计进展。

`tests/browser/practice-insight.js` 验证多轮练习、关闭覆盖层后的引用、针对性出题请求、同题历史和听写上下文。它使用模拟模型；回答质量及诊断准确性需真实模型试用评估。

本地联调按 [后端助手说明](../backend/README.md) 配置模型并启动后端，再启动前端。真实提问会产生模型 API 费用；自动测试使用模拟响应。代码入口：`assistant/AssistantPanel.tsx` 持有会话和共用界面，`assistant/useAssistantPresentation.ts` 管理布局、开关与原生模态行为，`pages/HomePage.tsx` 提供首页引导和上下文，`assistant/conversation.ts` 负责请求生命周期，`api/assistant.ts` 校验会话快照并统一 HTTP 错误，SSE 解析由 SDK 负责。

除 `npm test` 外，`tests/browser/assistant-layout.js` 提供布局交互回归。启动前端后，在前端目录用 Playwright CLI 打开本地地址，再执行：

```sh
playwright-cli open http://localhost:5173
playwright-cli run-code --filename=tests/browser/assistant-layout.js
```

脚本在浏览器拦截助手接口，不使用真实模型。覆盖首页与侧栏切换、会话和输入保留、等待中的请求、卡片状态、进入训练、应用到编辑器、窄屏焦点与滚动隔离。

## 常见节奏型输入

自定义新建页沿用练习工作区：顶部提供试听、名称和保存，主区提供谱面及编辑工具，设置侧栏提供节拍器、速度和小节数量。窄屏设置移至谱面上方，工具栏自然换行；保存错误在顶部显示，超拍提示仍位于编辑工具附近。小节删除确认、草稿恢复及保存流程保持原有规则。

编辑器提供二平均、四平均、前八后十六、前十六后八、小附点、反小附点、小切分、大附点、反大附点、大切分十种快捷输入。后三种各占两拍，其余各占一拍（以四分音符为一拍）。工具以“基础音符”“常用组合”分组；基础工具与常见节奏型常驻并排，空间不足时上下排列，按钮采用轻边框；删除末尾与清空小节提供文字标签。快捷输入一次追加整组普通音符，超拍时整组拒绝，不改变数据格式，添加后仍可逐音符编辑；三连音继续按原有分组规则处理。

## 页面返回恢复

练习详情共用紧凑题头：预设和自定义显示返回入口及原题名，随机练习仅显示返回入口。题头不重复主题、模式或存储来源，宽屏一行优先，长题名自然换行；返回仍使用原有历史恢复机制。

浏览器后退／前进恢复对应历史记录的状态与滚动；新访问浏览列表继承本次会话的最近选择和位置。预设保留模式、主题及两栏滚动，练习记录保留筛选与页码，自定义列表按模式保留分页。设置侧栏入口记住上次分类，显式 URL 分类优先。随机、自定义的侧栏仍进入模式选择页，不自动跳进练习或编辑器。练习和编辑页的新访问从顶部开始。页面内“返回”链接优先回到当前会话已有的目标历史记录，没有已知来源时按普通链接打开；修饰键和新标签打开保留原生行为。

练习记录列表和详情尝试均每页 10 条，最新在前；单页隐藏分页控件。切换模式回到第一页，删除导致空页时退到最后有效页。详情每次打开从最新一页开始，切换题目预览保留详情页码，关闭详情不改变列表页码；序号按展示顺序跨页递增（1～10、11～20），不代表第几次练习，全量统计不随分页改变。听写小节明细随所属记录展开。分页不改变记录规则或存储格式。

记录页在列表上方展示数字摘要，标题右侧提供近 7 天／近 30 天／全部（默认全部），与模式筛选共同作用于统计和题目列表，切换任一筛选回到第一页。统计按尝试计算、不受分页影响：击拍按结束日期，听写按开始日期；本地日历含今天，跨模式同一天只计一天。独立完成指完成前未查看答案，无击拍数据时通过率为「—」。列表按范围内最近练习排序，详情始终展示单题全部历史，删除仍删除整道题的全部历史并实时更新统计。筛选作为会话浏览偏好保留，不新增存储字段，不采集时长或推断能力变化。

预设列表在右栏主题标题旁统一选择击拍或听写，长标题或窄屏时自然换行。桌面右栏标题与模式固定，下方题目列表和左侧主题导航各自滚动，不带动全站导航或另一栏。切换主题或模式时题目列表归零，返回列表时恢复两栏滚动位置。窄屏改用主题选择框和普通页面滚动。切换主题不改变训练模式，无对应题目时显示空状态，不展示未开放模式。

`navigation/PageVisits` 不缓存服务器数据或组件。`useBrowsingState` 让新访问继承最近浏览偏好，同时为每次访问独立保留快照；`useVisitState` 仅用于该次访问的状态，不跨新访问继承。路由内容仍按历史记录 key 挂载。新增异步页面的加载占位须标记 `data-navigation-pending`，内容就绪后才恢复滚动；用户主动滚动会取消恢复。实例题库重新获取原分页数据，空页退到最近有效页。

快照仅保存在当前应用实例内，刷新或关闭页面后不保留。自定义新建草稿也按历史访问保存名称、小节内容、选中小节及生效的 BPM／节拍器开关，模式隔离；返回原记录恢复，重新点击“新建”创建空草稿。保存失败保留，确认成功后仅清除提交版本，不清除离开后继续编辑的新版本；不自动保存到题库。不恢复谱面内部滚动。离开练习仍卸载播放器并停止音频，不恢复播放、预备拍或正在运行的轮次；主题与击拍精度继续使用已有偏好存储。

随机练习按历史记录保留生成配置和当前题目，返回不重新生成，已有题目时不自动展开设置抽屉。听写三种来源共用 `PracticeWorkspace` 的作答快照，恢复答案、选中小节、逐小节验证结果、播放范围及生效设置。`DictationState` 以题目内容和题目编号共同校验绑定：换题即使内容相同也清空作答，同编号自定义题内容变化后也不沿用旧答案。听写组件只接收作答状态，不直接访问路由存储。结果遮罩、参考答案显示状态、音频与预备拍不恢复；新访问从默认状态开始。

随机生成配置跨新访问保留，重新进入模式时按该配置生成新题目；空范围保留并提示选择，不回退默认范围。历史返回仍恢复当次题目，不重新生成。浏览偏好只存在于当前应用实例，刷新后重置，URL 中的设置分类仍有效；不扩展答案、草稿、播放或弹窗的恢复范围。

回归检查：侧栏切换后预设选择和记录筛选保留，历史返回仍恢复原快照；刷新重置会话偏好；设置入口回到上次分类；随机配置保留但新访问不沿用旧题；自定义分页及滚动恢复、删除后空页回退；直接打开题目时返回入口可用。

## 练习交互

预设题头提供上一题／下一题，仅在当前主题、当前训练方式内切换，首尾禁用，不自动跳题。切题通过路由卸载旧工作区，停止声音和未完成的启动请求。三种来源在题头提供当前内容版本的本地练习历史，复用记录详情抽屉；历史成就与本次结果分开展示，听写区分独立完成与查看答案后完成。

题名旁只显示历史完成状态：击拍「✓ 已通过」，听写「✓ 已独立完成／✓ 已完成」；未完成不显示状态。有记录即可打开历史，无记录时入口禁用。切题和随机生成设置统一放在题头右侧，本次结果仍在练习工具栏。

听写使用 `R` 切换查看答案／返回作答，与按钮共用操作及记录规则；返回作答不记录查看答案，完成后的复盘不更改练习记录。

击拍快捷键：`H` 开始、`L` 试听、`S` 停止（含声音准备阶段），空格击拍；预设切题：`P / N`；随机换题：`N`（播放期间禁用）。工具栏「快捷键」浮层只列出当前模式及来源支持的操作，点击外部、关闭按钮或 `Esc` 收起；按钮悬停提示对应键位。输入框、可编辑区域、链接／按钮聚焦、弹窗或快捷键说明打开及输入法组合输入时不触发全局练习快捷键。记录粒度、存储格式及已有历史返回恢复规则不变。

听写“查看答案”在原谱面窗口切换为只读参考谱面，不再在页面底部展开。参考模式明确标注“参考答案”，编辑工具和验证按钮不可操作但保留占位；点击“返回作答”恢复原草稿、选中小节、验证状态及横向滚动位置。参考谱面与草稿分别渲染，答案不会传入草稿编辑回调，查看答案不会触发通过结果；播放操作仍保留原有含义。

听写快捷键：`L` 播放题目、`A` 播放我的答案、`S` 停止（包含声音准备阶段）、`V` 验证当前小节。播放范围沿用当前选择；重复按正在播放的来源键不重启、不重复计数，换来源则切换播放。空答案不能播放，查看参考答案时不能验证；未修改答案的重复验证不计数。自定义题目编辑器不启用这些快捷键。

听写顶部的“仅播放当前小节”同时控制题目和我的答案：默认不勾选，播放整题；勾选后显示当前小节编号，播放所选小节。切换范围仍停止当前播放，保留草稿与验证结果。

作答、编辑与参考答案共用单行谱面：宽屏双小节利用可用宽度，长题和窄屏在谱面窗口内左右滚动，编辑工具不随横向滚动移动。同宽窗口下，小节宽度、符号倍率和谱面高度不随小节数量变化；单小节左对齐，右侧留白。小节宽度按十六分音符容量预留，增删音符不改变小节边界或重置滚动位置；空小节不补休止符，编号使用 VexFlow 内置小节号。

谱面上方的小节导航列出全部小节并突出当前项。点击数字同步编辑位置，仅在目标未完整可见时横向定位；点击谱面也同步导航，手动滚动不改变选中小节。返回恢复草稿时，等待窗口宽度就绪后将选中小节带入视野一次（窄屏对齐小节起点），不恢复精确的历史横向位置；随后编辑、手动滚动或调整窗口尺寸不自动拉回。参考答案使用独立的浏览导航，不影响作答的选择及滚动位置；两种模式保留相同的导航行高度。

当前支持击拍练习、节奏听写，以及预设、随机和自定义三种题目来源；几何游戏未开放。自定义练习的保存、列表和练习记录无需登录。

## 练习控件

预设与自定义题目区最大宽度为 720px，在公共框架内左对齐；题目使用最小高度 64px 的整行链接与淡分隔线，悬停显示浅色底，键盘聚焦显示轮廓。预设模式切换宽屏位于主题标题旁，窄屏移至标题下方，自定义“新建练习”位于题目区上方并右对齐；窄屏随可用宽度收缩，长题名换行。首页和模式入口也使用共用导航行样式，保留各自的图标与说明。

全站桌面采用固定窄导航，图标配简短文字；视口宽度不超过 1000px 时改用移动页头和菜单抽屉。正文最大内容宽度为 1440px，结合导航占位及响应式左右留白收缩。功能页标题、返回栏与内容外边界遵循统一正文基准线，较窄的列表与设置内容在公共框架内左对齐；预设主题导航与设置分类共用侧栏宽度和列间距，窄屏改为上下布局。页面、工作区及谱面颜色使用语义变量，支持浅色与深色模式。

击拍工作区顶部组合击拍／试听、紧凑节拍器、BPM 与减号／加号图标按钮（每次减／加 5 BPM，到达 40／240 时禁用），下方谱面与反馈使用工作区宽度排列。窄屏控制区自动换行，不重建训练或重置设置。谱面按可用宽度适度放大（最高 1.6 倍），排版和反馈共用缩放坐标。预设、随机和自定义击拍共用。

听写与击拍共用 `PracticeFrame` 布局：顶部组合播放操作、播放范围、紧凑节拍器与 BPM，以及快捷键等辅助操作；随机练习保留生成操作。下方作答／参考谱面、编辑工具和验证操作共用工作区宽度；听写的小节切换按钮紧邻谱面，不增加背景或外框，保留谱面原有编号、选中高亮与点击选择；删除与清空归入基础音符组，查看答案与验证在末尾靠右聚合。独立训练页采用统一底色，移除工作区外围卡片边框。控制区按工作区实际宽度换行，助手展开后播放区与调速区整组分行；基础音符组保留完整一行所需宽度，空间不足时与常用组合上下排列。覆盖层的历史完成状态紧邻标题，长标题允许换行。生成练习覆盖层直接承载工作区，不再嵌套一层卡片边框。框架不持有播放或作答状态，调速／切换范围仍只重建播放器，保留草稿与验证结果，换题才重置作答。自定义新建页保留独立的编辑布局：顶部放名称、试听和保存，设置区放节拍器、BPM 与小节数量；设置在 DOM 中先于谱面，宽屏置右、窄屏置上。

随机击拍与听写首次进入即按默认范围生成两小节题目，不自动播放、不自动打开设置；同一历史记录返回时恢复原题及配置，不重复生成。生成配置放在右侧抽屉，窄屏占满宽度。标题、小节数和练习范围标题固定在顶部，空选或生成失败的提示紧跟范围标题，不随选项滚动。范围分为音符、休止符、节奏型三个分组，每项独立勾选并显示真实记谱图形；音符与休止符宽屏双列、窄屏单列，节奏型单列，整个选项区独立滚动。抽屉不提供生成或提交按钮，支持关闭按钮、Esc 和遮罩关闭；关闭保留当前历史记录内的材料、小节数选择，不立即换题，也不保存到浏览器。修改配置后仅通过工作区“换一题”应用新配置出题，失败打开抽屉提示；范围为空时禁用生成。音频准备及播放期间禁用生成和设置入口，换题保留 BPM 与节拍器设置。预设和自定义练习不显示这些入口。

随机范围表示允许使用的材料，不保证每题覆盖全部选项。默认选中全音符、二分音符和四分音符；支持单独音符、附点四分／八分音符、五种休止符及十一种节奏型（含小三连）。节奏型整组生成，无需勾选其基础音符；普通材料按自身网格放置，附点四分／八分音符与一拍节奏型从拍头开始，两拍节奏型从第 1、3 拍开始。生成器只使用勾选材料，无法填满 4/4 小节时提示增加其他材料，不自动补入未选音符或休止符。编辑器快捷输入和随机组合复用 `rhythm/RhythmPatterns.ts` 定义，显示预览与生成内容保持一致。

击拍谱面使用 VexFlow 内置小节序号，编号位于对应小节左上方；滚动窗口根据屏幕高度容纳完整的一至两行。击拍／试听按音频时钟定位的事件（含休止符）跟随谱行，两行窗口保留当前行与下一行；滚动采用按行切换，不连续移动音符，也不重建谱面或改变判定。滚轮、触摸、滚动条或方向／翻页键操作会暂停本轮跟随，可点击“继续跟随”恢复。停止或结束后保留位置供复盘，新一轮回到首行并恢复跟随；听写和编辑谱面不受影响。

音频加载时仅对应的开始／试听按钮显示“准备中…”。预备拍用半透明深色遮罩压暗谱面可视窗口，中央显示倒数（默认 4、3、2、1），读取现有音频时钟，点击不关闭，正式开始立即消失，不增加额外拍。击拍过程只保留音符下方的判定标记。自然结束后在工具栏显示“✓ 本次通过／× 本次未通过”，保留谱面标记，不使用结果遮罩或 Toast。重新开始或调整配置会清除旧结果；正式开始后主动停止显示未通过并保留结算标记，试听结束及准备、预备拍内停止不显示结果。结果区域预留空间，避免出现时改变工具栏高度；音频错误也在顶部操作栏提示。

听写复用击拍的 `PracticeCue` 预备拍倒数：播放题目和播放答案的预备拍由原有音频时钟倒数，正式播放、停止、调速、切换范围或小节时清除。单小节验证在对应谱面左上方显示“✓ 正确／× 有错误”，随小节横向滚动；小节导航同步显示红叉或绿勾，紫色仍只表示选中。修改该小节后同时清除两处结果，其他小节不受影响；未验证不显示标记。全部小节验证正确才在工具栏显示“✓ 全部通过”，单小节错误不视为整题失败。查看参考答案和播放结束不触发通过，重新播放或编辑会清除旧整体结果。草稿编辑器与谱面只接受验证状态并统一呈现，不负责判定。

编辑器的“清空当前小节”直接清除当前小节全部内容，不弹确认框；保留小节及选中位置，不影响其他小节。空小节时禁用，清空后移除编辑提示；听写同时重置该小节验证结果，不修改标准答案或已保存的练习。

听写作答与自定义练习共用节奏编辑器：音符、休止符、小三连和附点使用音乐符号按钮，悬停可查看名称，也保留键盘操作和无障碍名称。“删除末尾”保留文字。图形沿用谱面的记谱规则，全／二分休止符带短参考线；工具栏在窄屏自动换行。添加、附点和删除仍作用于当前小节末尾，不改变容量限制。

练习设置中的机械节拍器可点击开启／关闭，与 BPM 控件放在一起。开启后随击拍、试听、听写及自定义试听的音频时钟左右摆动；空闲时不独立发声。中途关闭、停止或调速后摆杆归中，重新开启接上当前拍位；关闭时预备拍声音仍保留。系统启用“减少动态效果”时不摆动，声音和开关照常工作。

练习页面共用 BPM 调速控件（40–240，默认 60）：训练顶部使用减号／加号图标按钮，每次调整 5 BPM；自定义编辑页保留乌龟／兔子之间的滑块，松手后生效。两者均可直接输入，失焦或回车生效。回车确认合法数值后退出输入焦点（未修改也退出），空值、越界或非整数则保留焦点并提示。滑块支持键盘方向键和 Home／End。速度真正改变才停止当前练习／播放，不自动重启；击拍谱面保留，只清除本轮反馈。移出轨道松手仍提交，控件失焦或失去指针捕获不回退；真正取消操作（Escape、指针取消或窗口失焦）恢复原速度。非法值保留原速度并提示。听写和自定义编辑草稿不会因改速丢失，速度本身不持久保存。

## 数据保存

应用面向本地单人使用，无登录或账号状态。自定义题库与练习记录统一保存到本地后端 SQLite，助手对话保存到后端 JSONL；浏览器仅保留外观、击拍精度和当前对话 ID。未保存草稿仅在当前应用会话保留。

设置提供外观、本地数据、声音（未开放）、击拍精度四个分类，默认外观。设置 → 本地数据提供题库统计、记录摘要及清空操作。备份步骤见 [后端说明](../backend/README.md#数据与备份)。

自定义练习统一使用 `/custom/:mode/:exerciseId`。列表按每页 50 条从服务读取，进入题目后读取完整谱面。请求失败显示错误，不回退浏览器题库。编辑保存覆盖原 ID，失败保留草稿；删除需确认。

练习记录写入串行执行，跨标签页通过版本检查处理冲突，重试同一行为批次不重复计数。离页已提交的保存继续完成；失败行为可在站内返回后重试，刷新前先完成重试。换浏览器后从后端读取同一实例数据。

外观与击拍精度仍在当前浏览器保存，不影响题库；模型配置沿用后端环境变量，本次未新增配置页面。

## 练习记录

- 按来源、题目 ID、模式和节奏内容版本累计，不按页面访问分记录。预设和自定义再次进入沿用记录；改名不拆分，修改节奏分别记录，恢复旧内容会继续旧版本。随机每次成功生成分配独立编号，相同谱面也不合并；未练习不建空记录。
- 击拍：自然结束或正式开始后主动停止时追加尝试。主动停止一律未通过，保留实际命中和误敲，全部未命中目标（含尚未播放）计为漏拍；保存结束时间、速度与判定精度。以音频时钟进入题目为准，不依赖画面帧或是否敲过。准备、预备拍期间停止及试听不记录，调速、离页和卸载也不补记。自然结束的迟到输入修正同一尝试；主动停止废弃时钟，后续输入不改旧记录。
- 听写：一道题下保留多次尝试，一份空白作答对应一次尝试；首次有效听题、验证或查看答案才建立。每次保存开始时间、完成时间（未完成为 null）、是否查看答案及各小节的听题次数、验证次数、判定（未验证／正确／错误），不再跨尝试累计小节数据。
- 整题播放给本次所有小节加一次，仅播放当前小节只给该小节加一次；成功启动即计数，中途停止不撤回，播放自己的答案不计入。未改答案重复验证不重复计数；修改小节清除该小节判定，保留本次次数。仅编辑不创建尝试。
- 全部小节验证正确时记录完成时间并冻结该次记录，作答只读；之后播放或查看答案属于复盘，不改次数或查看答案标记。未全部正确则保留为未完成，验证错误不结束尝试。
- 不提供“重新练习”或“再做一次”按钮。站内后退恢复原草稿时延续原尝试；从列表重新进入或刷新从空白开始，首次有效操作后追加下一次尝试。
- 题目保留首次和最近练习时间，列表按最近时间倒序；听写每次尝试只含开始、完成时间，不含最近操作时间；击拍每次尝试显示完成时间。不统计时长。仅打开、编辑或重复验证不更新时间。
- `/records` 列表仅展示题目名称、来源和模式，右侧并列「查看详情／删除」操作；查看详情打开右侧抽屉。关闭按钮、Escape 或点击遮罩可关闭，保留列表筛选、已加载数量和滚动位置。窄屏抽屉占满屏幕。记录保存到本地后端，清理网站缓存不会删除已保存记录。
- 写入失败保留待保存行为并提供重试，站内返回也可重试；成功后移除队列，不保留操作日志。刷新前应先完成重试。记录操作不会影响自定义题库。
- 详情分「练习明细／题目预览」两种视图。两种模式均以表格每行展示一次尝试，最近优先，第一列为正序排列的列表序号；听写只在行内展开小节明细。轻量抽屉直接加载，不在正文插入加载占位；仅谱面预览按需加载，加载提示及失败重试都留在抽屉内，关闭始终可用。预览为只读谱面，不显示小节选择控件。删除位于列表行右侧，与详情入口分开，需确认。日期紧凑显示，悬停可查看完整时间。
- 本地数据以「自定义题库」和「练习记录」两组紧凑摘要展示，清空按钮对应归组，窄屏排到摘要下方。清空范围在确认弹窗中说明，成功使用可关闭 Toast；两类数据互不删除。

## 本地开发与联调

先按 [后端说明](../backend/README.md#本地运行) 在一个终端启动后端，再从仓库根目录另开终端运行：

```sh
cd frontend
npm ci
npm run dev
```

访问 Vite 输出的地址，默认 `http://localhost:5173`。[vite.config.ts](vite.config.ts) 将 `/api` 和 `/api/` 下的请求转发到 `http://127.0.0.1:8000`，保留路径。前端始终请求同源 `/api/...`，不要硬编码后端地址或额外开放凭证跨域。

在前端页面的浏览器控制台验证完整链路：

```js
const response = await fetch('/api/health');
console.log(response.status, await response.json());
// 200 { status: 'ok' }
```

直接访问后端健康检查不能验证 Vite 代理。代理失败时先确认后端已启动；8000 端口被占用时先检查现有进程，不重复启动。修改代理配置后重启 Vite。实例配置、Origin 与接口约定统一见 [后端说明](../backend/README.md#本地运行)。

### 页面验收


手动发送验证码会产生真实短信请求；费用与测试配置注意事项见后端说明。请求封装位于 [src/api/customExercises.ts](src/api/customExercises.ts)：错误状态 0 表示网络失败，502 也用于非法响应，取消读取保留 `AbortError`。

## 部署

Docker 启动见 [项目 README](../README.md#快速启动)，仓库中的 [Nginx 配置](nginx.conf) 已处理静态文件、独立题库和 API 转发。手动部署时需注意：

- 发布 `dist/` 中的构建产物；Vite 的本地开发代理不会随构建产物部署。
- React Router 使用普通路径，页面请求需回退到 `index.html`，保证直接打开或刷新 `/preset/:questionId` 等地址可以正常显示。
- `/api` 请求应交给后端，静态资源按实际文件处理，不能被页面回退规则吞掉。
- 客户端显示“未找到页面”不等于服务器返回 HTTP 404，状态码策略需由部署环境配置。

助手会话协议兼容 `assistant.tool_calls` 和 `tool_result`。成功的 `propose_rhythm_exercise` 结果在会话同步后显示为候选练习卡片，包含标题和按需加载的谱面预览（拍号在谱面内，小节通过紧凑导航切换），教学说明由助手回答提供；其他工具记录不直接展示原始 JSON。

自定义练习编辑器通过助手上下文注册应用入口。点击卡片“放入编辑器”直接覆盖当前草稿名称与节奏，选中首小节、停止旧试听，保留速度和节拍器设置；不自动保存，不检查生成时的草稿版本。保存期间暂停应用，离开编辑器后保留预览与试听。不同生成结果按消息顺序保留为独立卡片。

卡片先使用领域解析器验证结果，非法数据提示重新生成。卡片支持以可调速度试听整份练习（默认 60 BPM）（包含预备拍），可随时停止；卡片试听、页面播放和覆盖层训练在应用内互斥，启动新播放会停止旧播放。收起助手或新建对话停止卡片试听；卸载播放器时清理自身音频。支持进入现有击拍训练界面；同时支持进入听写训练，后端提示词与工具说明保持一致。

通用展示组件为 `exercises/ExerciseCard.tsx`，只接收练习与操作插槽；`assistant/tool-results/` 负责工具协议解析、连接当前编辑器及应用反馈。卡片不显示“候选”标签或重复的工具描述。

练习卡片按选中小节渲染单节谱面，不通过滚动长谱面模拟切换。数字导航按内容收拢，谱面保留原小节编号；工具标题约束只影响新生成的练习名称，不改写旧记录。

AI 卡片的“开始击拍／开始听写”将生成练习加入当前身份的临时题目集合，并在当前页面上方打开训练覆盖层。对话、路由与导航高亮保持原位；关闭后恢复触发点，后台练习不会自动恢复。覆盖层复用 `PracticeWorkspace` 的设置、判定及记录逻辑，无需先保存到题库。中断后台击拍沿用手动停止规则：准备及预备拍阶段不新增记录，正式训练中断记录一次未通过。临时题目在新对话后仍保留，刷新或切换身份后清空。`/ai/tapping/:exerciseId` 和 `/ai/dictation/:exerciseId` 仍支持已有临时题目的独立页面访问；未知题目显示失效提示，卡片不再导航到这些路由。

练习记录支持 `ai` 来源，界面显示“AI”，同一生成 ID 累计尝试，不同生成结果分别记录，保存谱面快照供之后查看。记录统一保存至实例后端。生成练习的领域类型与校验位于 `exercises/GeneratedExercise.ts`；工具结果组件只负责解析入口与操作连接。

生成练习的 `mode` 为 `tapping` 或 `dictation`，读取旧 `intent` 时将 `practice` 转为 `tapping`、`dictation` 保持不变，缺省为 `tapping`。听写题卡片默认不挂载谱面，提供试听、查看答案和进入听写；普通卡片仍展示谱面。模型提示要求听写标题和回答不泄露答案排列，但这是模型行为约束，不是文字内容的确定性过滤。

答案展示状态按生成 ID 在当前身份的内存集合中单向累计。卡片查看、应用到编辑器、进入击拍和听写页查看答案都会标记。进入听写不自动创建记录，首次播放或验证时携带已查看状态；已有尝试期间从卡片查看答案立即更新记录。重新隐藏界面或重新进入题目不会恢复为未查看，每张卡片只提供对应方式的训练入口，访问不匹配的训练路由会替换为题目对应方式。

卡片提供对应的训练按钮（进入击拍或进入听写）；底部按钮集中左对齐，统一高度、圆角和图标尺寸；试听与查看答案使用描边样式，开始练习使用实心主色。试听不显示独立的预备拍、播放中或结束状态小字，以试听按钮状态反馈进度，播放错误仍提示。卡片头部只展示标题，不显示小节数、答案隐藏或已查看的小字提示。听写卡片底部提供查看答案；展开后显示小节导航与谱面，按钮原位切换为“收起答案”。收起只折叠卡片谱面，不撤销已查看答案记录；同一卡片挂载期间保留折叠选择，重新载入会话时已查看的答案仍展开。编辑页的“放入编辑器”和进入训练为并列主操作，均使用实心按钮；成功反馈显示在编辑器工具栏，重复放入会重新提示。

卡片整首试听固定使用 60 BPM，不显示调速控件；进入练习后可在训练面板调速。旧会话的卡片速度字段保留兼容，但不再影响试听。

`tests/browser/assistant-stream.js` 暂停工具后的模型回复，验证卡片提前可用、最终同步保持卡片节点，以及后续失败或停止仍保留已生成练习。

### 页面布局与练习入口

普通浏览页在主区域限宽居中，内容内部左对齐；关于页使用较窄的阅读宽度，练习和编辑页保留宽幅工作区。随机入口 `/random` 直接进入练习，可在题头切换击拍／听写、换题与打开生成设置。自定义入口 `/custom` 直接进入题库，顶部切换模式并新建题目，练习与编辑仍使用独立子页面。两个栏目分别记住本次浏览中的模式选择，首次默认为击拍；刷新保留当前 URL 中的模式。原有子页面地址保持兼容。

自定义编辑器的名称错误显示在预留的字段提示行并聚焦输入框；小节拍数错误切换到对应小节，复用谱面下方的固定反馈区。编辑器保存失败、练习记录保存失败和音频错误使用可关闭的浮动提示，保存失败提供重试；错误不自动消失。助手放入编辑器使用成功浮动提示，均不推动谱面。

题库删除、记录删除、设置清空数据的操作结果统一使用浮动提示：成功短暂显示，失败保留至关闭。随机练习范围校验保留固定提示空间；页面读取失败仍在内容区域显示。重复操作失败时允许重新显示已关闭的提示。

窄屏首页会话列表展开时将焦点移入列表，Tab 在列表内循环，Escape 或关闭按钮收起后返回入口；正文暂时不可交互，切换到宽屏自动退出覆盖模式。`tests/browser/responsive-feedback.js` 覆盖 320–1024px 练习页与编辑器、生成设置焦点返回，以及长消息和多卡片下的会话列表交互。

开发时可用 `BACKEND_URL=http://127.0.0.1:8017 npm run dev` 指定代理目标，默认仍为 8000；相应页面来源需加入后端 `ALLOWED_ORIGINS`。浏览器回归脚本需要独立测试后端和数据目录，不要对日常数据运行清空测试。

练习记录模块分工：`practiceRecords.ts` 负责行为计算，`practiceRecordValidation.ts` 负责读写边界的结构校验，`practiceRecordStorage.ts` 负责服务端读写、版本冲突和重试。本地数据设置由 `LocalDataSettings.tsx` 统一呈现题库与记录管理。
