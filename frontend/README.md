# 节奏训练前端

## 本地运行

```sh
npm install
npm run dev
npm test
npm run lint
npm run build
```

## 源码目录

`src/` 按职责组织，文件名与导出接口保持独立，不通过统一的 `index.ts` 转导出。

```text
src/
├── main.tsx、App.tsx、App.css、index.css  # 应用入口、路由与全局样式
├── pages/                              # 路由页面、题目选择和生成配置
├── practice/                           # 共用工作区、击拍和听写交互
├── rhythm/                             # 节奏模型、计时判定和音频
│   └── notation/                       # 谱面转换、绘制和反馈定位
└── exercises/                          # 预设题库与题目生成器
```

页面负责提供题目，`practice/PracticeWorkspace.tsx` 管理 BPM 与节拍器设置，再交给对应练习组件。练习组件使用 `rhythm/` 的共享能力；共享能力不依赖页面或题目来源。听写内部的编辑、判题和答案谱面仍保留在 `practice/RhythmDictation.tsx` 内。

测试继续放在 `tests/`，计时与生命周期说明见 [TIMING.md](TIMING.md)。

## 页面与内容

- `/`：练习库，在主题内选择训练模式，再列出该模式的预设题目，不另设主题详情页。
- `/practice/:questionId`：练习页，例如 `/practice/eighth-notes-01`。
- 未知题目显示“未找到该练习”，未知路径显示“未找到该页面”，都可以返回练习库。

使用 React Router 的声明式路由（BrowserRouter、Routes、Link），参考[官方接入说明](https://reactrouter.com/start/declarative/installation)。题目地址可以直接打开、刷新，支持浏览器前进和后退。页面切换后阅读位置回到顶部，焦点移到主要内容。

`exercises/presetExercises.ts` 是预设内容的唯一来源：主题包含 `modes`，每个模式分组包含自己的 `questions`；题目包含 ID、标题、说明和 RhythmExercise。题目 ID 全站唯一，修改题目名称时保持 ID 不变。本次以正式预设替换演示题目，旧演示题目地址不再保留。查找题目同时返回所属主题和模式，不在练习页切换同一道题的模式。

网站模式是 tapping（击拍练习）、dictation（节奏听写）、geometry（几何游戏）。每个主题的三组题库互相独立；当前十三个主题共有 58 道题（分别为 3、6、5、5、4、4、4、5、4、4、4、5、5 道），都属于 tapping，另外两组为空且未开放。击拍组件内部的 practice/listen 表示练习/辅助试听，不是网站的三种模式。未实现的模式即使添加题目，也不会自动使用击拍组件运行。

随机和自定义仍未实现；后续也采用“主题 → 模式 → 生成/编写题目”的归属关系，不把一份题目自动共享给三种模式。添加预设内容编辑数据文件即可；开放新模式还需要接入对应训练组件。暂时没有后端、账户或进度保存。

`pages/ExerciseLibrary.tsx` 负责列题；`pages/PracticePage.tsx` 负责选择题目和生效 BPM；`practice/RhythmTrainer.tsx` 保留试听、击拍、音频生命周期及结果展示。进入练习页才加载训练和 VexFlow 代码。随机、自定义、听写和几何可视化入口明确标记“未开放”，不会进入空白页面。

## 配置与结束规则

界面只显示选题和操作所需的信息：练习库保留主题、主题内模式入口、题名与小节数；练习页标明“主题 / 所属模式”，保留标题、速度、谱面和操作按钮，不提供模式切换。主题及题目 description 仍保存在数据中，但暂不呈现。

BPM 草稿与生效值不同才显示“未应用”；提交无效值时就地提示范围错误，不修改当前速度或中断训练。闲置时不显示“尚未开始/等待敲击”，预备拍、即时判定与结束结果按阶段呈现。空格键提示保留在操作按钮附近。

BPM 默认 60，允许 40–240 的整数；输入框是草稿，应用或回车后生效。应用新速度停止当前轮；同值应用不打断。题目切换、离开页面停止并清理旧训练；刷新和重新进入不恢复旧成绩或速度。预备拍和判定窗口仍使用训练组件默认值。

核心时间模型见 [TIMING.md](TIMING.md)。`npm test` 明确运行时间/判定测试和练习库数据测试，后者覆盖题目 ID、查找失败与58 道预设的顺序、逐小节音符内容、四拍时值与不同 BPM 下的连续时间线。页面导航、声音资源清理和响应式布局还需浏览器验证。


事件支持 `dots?: 0 | 1`：省略或 0 为无附点，1 为单附点，音符和休止符共用。`rhythmEventToDurationInQuarterNotes()` 统一计算完整事件时值（单附点为基本时值 × 1.5），普通事件经它换算后转为整数 tick，再由统一展开结果供时间线和连梁分组使用。VexFlow 的 `dots` 设置内部时值，`Dot` modifier 绘制附点；声音和判定不增加专用分支。十六分音符使用 `noteValue: "sixteenth"`，基本时值为 0.25 拍，对应休止符与单附点也支持。附点全音符虽然可计算为六拍，但不能放进当前四拍小节。

每小节必须填满 4 拍，生成时间线前检查；欠拍、超拍或空小节会抛出带小节编号的错误。现有题库测试会遍历题目并生成时间线，从而同时校验所有预设内容。校验失败目前属于内容开发错误，尚未提供面向用户的编辑器错误界面。

## 谱面布局

谱面按容器宽度以完整小节换行，每行小节等宽，末行保持相同宽度并左对齐。每行显示谱号，仅全曲开头显示拍号。极窄容器统一缩放谱面与反馈，避免带拍号的密集八分音符被裁切。

`rhythm/notation/RhythmScoreLayout.ts` 负责行列布局及时间到二维反馈位置的映射；`rhythm/notation/RhythmScore.tsx` 观察容器宽度并绘制。命中和漏拍跟随目标音符，误敲按时间选择小节；换行边界属于下一小节。宽度变化会重绘并重新定位已有反馈。布局、窄屏缩放和跨行映射由 `npm test` 覆盖。

当前仍在反馈变化时重绘全谱，尚未添加当前行自动滚动；长谱面可能需要纵向滚动。


同一四分拍内的连续八分、十六分音符（含单附点）可混合连梁，支持 EE、SSSS、ESS、SSE、E.S 和 SES（S 为十六分音符）。休止符、长音和跨拍事件断开分组；单个音符保留符尾，不跨小节。`rhythm/notation/RhythmScoreLayout.ts` 按音乐时值生成小节内分组，渲染层在排版前创建 VexFlow Beam、排版后绘制。每个音符仍独立播放、判定与高亮，共用连梁保持黑色；数据模型和时间线不变。

## 部署时需要注意

BrowserRouter 使用普通路径。Vite 本地开发支持页面回退；部署到静态服务器时也必须配置：**非静态资源的页面请求回退到 `index.html`**。否则直接打开或刷新 `/practice/eighth-notes-01` 会得到服务器 404。具体 rewrite/fallback 配置取决于之后选用的托管平台，本次不部署网站。

当前未知路径是客户端 404 界面，不等于服务器返回 HTTP 404 状态。生产环境的状态码策略可在确定托管方式后配置。

密集小节按 VexFlow 最小排版测量、行首符号余量及每事件阅读间距确定最小宽度，优先减少每行小节数，极窄屏仍整体缩放；谱面和反馈共用缩放坐标。320px 屏幕上的密集谱面仍然较小，尚未增加放大阅读功能。

十六分音符在 BPM 120 下间隔 125ms，相邻命中窗口会重叠，仍按最靠前待匹配目标判定。新增音符没有修改窗口或难度标准；测试覆盖 60、120、240 BPM 的时间线与顺序命中。


## 小三连与整数音乐时值

小节使用 `elements`，元素可以是普通 `RhythmEvent` 或 `{ kind: "triplet", notes: [...] }`。第一版三连音组恰好包含三个无附点八分音符，从四分拍头开始，共占一拍；不支持组内休止符、其他时值、嵌套或跨拍。旧题目只迁移字段名，内容不变。

`expandRhythmElements()` 统一输出独立事件、小节内起点 tick、时长 tick 和三连音组下标。每四分拍 24 ticks，八分 12、十六分 6、附点十六分 9、三连音每音 8；每小节校验总和为 96。小节和事件音乐位置使用整数累计，再按 `绝对 tick / 24 * (60000 / BPM)` 独立换算起点和终点，不累计近似的三分之一拍毫秒数。

`eventIndex` 仍是展开后包含休止符的全局事件编号。三连音的三个音符分别发声、高亮和判定；判定窗口及统计不变。VexFlow Tuplet 在排版前关联三个八分音符，按 3:2 改变内部时值并显示“3”，每组独立连梁。内部 24 ticks 不是 VexFlow 的时间单位。
