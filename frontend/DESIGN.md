# 通用界面规则

本文维护视觉与交互原则。具体数值以 [design-system.css](src/design-system.css)、[App.css](src/App.css) 和组件样式为准；运行与验收入口见 [前端说明](README.md)。

## 视觉与样式归属

- 页面、工作区、谱面、边框与状态使用语义颜色变量，适配主题和明暗模式；不固定白底黑谱或单一主题色。
- 成功、错误、选中和悬停各有明确含义，反馈同时提供文字或形状，不只靠颜色。
- 主操作由当前任务决定，试听、历史等辅助操作保持次级。导航和分类采用平面反馈，操作按钮使用一致的按压反馈。
- 布局和通用控件优先修改共同规则；业务组件样式放附近，不为纯样式增加转发组件。
- 音乐符号复用记谱规则，通用图标使用 Lucide，品牌标记使用项目自身素材。

## 布局与内容稳定

- 播放、编辑、反馈和设置按当前可用宽度排布；助手展开和窄屏重排不能重挂载训练或丢失草稿。
- 把主要操作和辅助操作分组；长题名和工具栏自然换行，不靠挤小点击区域解决溢出。
- 预留必要的结果／校验提示空间，避免反馈出现时推动谱面。浮动操作提示与字段错误采用不同位置。
- 会话列表删除入口的显隐独立于禁用态；切换等待复用列表的加载反馈，不挤动消息区，新会话在首帧绘制前完成滚动定位。
- 异步界面区分首次加载、已有内容更新和读取失败。首次加载用稳定占位，更新保留上次结果及其统计口径，完成后整体替换；提示预留空间，短请求不显示加载文字，失败保留结果并提供重试。
- 请求与缓存由 TanStack Query 管理，列表／详情用 `ui/useRetainedData` 保留上次展示结果直到新查询成功，失败时仍保留；加载反馈复用 `ui/AsyncStatus` 和 `LoadingPlaceholder`。跨题身份不借用旧作答或成绩；训练重建仍用于释放旧音频。
- 击拍谱面可按行跟随，用户手动浏览后暂停自动跟随；听写作答、编辑和参考答案保持各自的浏览位置。
- 只读参考答案与用户作答分开，查看答案不得触发作答编辑或通过判定。

- 路由切换不做整页淡入；模块未就绪时通过稳定的 Suspense 边界保留已显示正文，首次打开仍使用加载占位。页面就绪后在绘制前恢复滚动与焦点，训练与编辑仍按访问重建。

## 交互、焦点与错误

- 所有操作有可访问名称及可见键盘焦点；选中状态与焦点状态分开。
- 全局练习快捷键避开输入、可编辑区域、控件焦点、输入法组合输入和其他模态层。
- 模态浮层隔离背景焦点并锁定背景滚动；关闭恢复合理触发点，关闭方式按场景明确提供。
- 离开训练或关闭练习先停止音频，再完成视觉退出；快速开关和布局切换不能遗留关闭回调。
- 系统减少动态效果时关闭相关动效，声音和必要状态反馈仍可用。
- 字段错误靠近字段并帮助定位，读取失败在内容区提供重试；保存失败保留草稿并提供重试，错误不自动消失。
- 破坏性操作明确范围并确认，普通编辑操作避免不必要的确认。成功提示短暂显示，重复失败仍可再次呈现。

## 验收范围

共享布局先验证击拍与听写，再检查受影响的列表、编辑器或设置。检查桌面、窄屏、断点两侧、助手展开、长内容、主题／明暗模式、键盘与减少动态效果。
播放或保存相关变化还需验证关闭／离页、失败重试与状态恢复；回归脚本见前端 README。
