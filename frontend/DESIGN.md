# 通用界面规则

本文维护视觉与交互原则。具体数值以 [design-system.css](src/design-system.css)、[App.css](src/App.css) 和组件样式为准；运行与验收入口见 [前端说明](README.md)。

## 视觉与样式归属

- 页面、工作区、谱面、边框与状态使用语义颜色变量，适配主题和明暗模式；不固定白底黑谱或单一主题色。
- 成功、错误、选中和悬停各有明确含义，反馈同时提供文字或形状，不只靠颜色。
- 主操作由当前任务决定，试听、历史等辅助操作保持次级。导航和分类采用平面反馈，操作按钮使用一致的按压反馈。
- 布局和通用控件优先修改共同规则；业务组件样式放附近，不为纯样式增加转发组件。
- 音乐符号复用记谱规则，通用图标使用 Lucide，品牌标记使用项目自身素材。

## 游戏像素主题

像素风保留双球与镜头的连续运动。背景和球体纹理使用平滑像素采样，道路、圆周与功能符号按背景像素网格绘制后最近邻放大；不对整屏应用颗粒滤镜。数字和界面文字优先保证辨识，不机械缩小到背景分辨率。哑光主题保持平滑材质。

工作区统一使用青绿／暖金双球、有限色阶道路、Fusion Pixel 标题与主按钮、系统字体辅助信息和平直硬边控件；全局导航保留应用公共外壳。主题只改变场景美术，不能改变音频时钟、旋转、判定或路线。像素关卡共用界面语义色与基础反馈，道路色阶不再影响按钮、弹窗、成功或失败颜色。主题与素材的维护入口见[游戏内容制作](src/game-content/README.md)。

### 构图与反馈

目录以圆角场景缩略图、曲名、时长与 BPM 识别曲目，整卡提供统一点击与悬停反馈，不另加箭头，不单独缩放封面；支持悬停的设备上整卡轻微放大，减少动态效果时关闭放大；长曲名自然换行，同一行的元信息底部对齐，列数随可用宽度变化。基础节奏单独分类，以浅纸色节奏海报、序号、标题和节奏要点组成卡片；谱例与关卡内墙上海报共享选谱和像素记谱规则，单项展示两拍重复，混合和综合并列展示两条谱例，不重复叠加起音点阵；保留逐行学习顺序，按内容区宽度排成三列、两列或单列。关卡页顶栏保留返回、曲名和开始／示范／设置三个固定操作，开始与示范等宽等高，开始／停止原位切换。手机将开始与示范并排放到顶栏第二行。设置以速度、练习范围、关于乐曲三个同级分区排列，桌面标题与内容分列、手机单列。速度直接输入并可恢复默认；范围始终显示起止小节，乐段名附在对应小节选项中；关于乐曲常显。打开设置聚焦标题，不自动选中输入。草稿取消不生效，应用才生效；正文独立滚动，底部操作保持可见。不设玩法说明或主题选择，不常驻显示进度计数、范围摘要或示范结束提示。舞台无描边，场景铺满整个游戏工作区，返回、标题和操作叠在场景上；顶部以局部渐变保持可读性，只有按钮与返回链接拦截点击；失败与挑战完成才在场景中下部显示无边框的大标题，结果区仅显示标题，成功统一为“完成”，失败只保留顶栏的“再试一次”；手机结果区靠下避开球与失败标记，结果出现不改变舞台尺寸。背景保持比例裁切，通过各场景取景参数适配宽屏与竖屏。人物和叙事主体留出安全边距，中央读路区域保持低对比，检查桌面与宽屏实际舞台；手机检查按任务需要进行，不作为默认必检项。

视觉层级为背景弱于道路、双球突出于道路，功能符号保持清楚。背景压暗由主题配置，静态场景与时间线场景使用一致的遮色规则。场景过渡按音乐位置发生；减少动态效果时取消渐变、拖尾和装饰性命中动画，保留必要的圆周提示、落点颜色和失败标记。

所有像素关卡的已走及范围外道路使用公共的不透明度规则，隐藏像素功能标记，当前锚点保持清楚。完整终点以方格终止带和落地反馈区分，片段终点保留开口环；球落地后仍需辨认终点。变速数字采用带底色的窄边铭牌，短杆指向地块。舞台不显示辅助小字（即时判定、误敲计数、准备／加载说明、收尾提示、结果范围和速度）；保留预备拍大数字、结果标题和操作，进度与判定文本仅供辅助技术读取。运行时禁用设置。

### 配色与素材尺度

道路使用阴影、面色、亮边、符号四个有明确用途的色阶，颜色从暗到亮递增。符号对路面的相对亮度对比以 4.5:1 为验收参考，仍须结合实际场景检查。已有石径功能符号约 4.494，作为已验收的设计例外保留；铜钉／嵌石的约 4.18／3.06 是装饰配色，不作为功能符号的标准。

球体保留深轮廓、分层明暗和左上受光；路面使用实色面层与窄亮边，避免大面积渐变或模糊发光。球径由地图尺度决定，不随素材尺寸改变。已走及范围外道路保留原有面层、侧壁、描边和材质，完整合成后按公共透明度整组淡化，避免各层叠色；功能标记不进入淡化层。

素材以粗颗粒背景为制作方向，现存细颗粒场景允许逐张迁移；运行尺度由 [PixelDrawing.ts](src/game/rendering/PixelDrawing.ts) 定义。图像尺寸和导出倍率以[内容制作说明](src/game-content/README.md#美术源与导出)中约定的资源声明为准，本文不另维护规格表。通用素材的造型约束见内容制作说明，单关构图与改编理由留在本关 README。

## 全站导航

主导航按助手、练习、游戏组织，设置与关于放在辅助区域。“练习”固定进入 /practice，提供预设练习、随机练习、自定义练习、练习记录四个同级入口。各子页面保留独立地址、标题及原有工作区布局，通过“返回练习”回到入口；题目详情和编辑页仍返回所属列表。练习子页面统一高亮侧栏“练习”，不叠加来源切换栏。导航沿用既有未保存保护和访问恢复，不缓存运行中的音频。

## 布局与内容稳定

- 播放、编辑、反馈和设置按当前可用宽度排布；助手展开和窄屏重排不能重挂载训练或丢失草稿。
- 训练工具栏左侧放播放／练习操作，右侧放范围开关、速度和节拍器，窄屏按组换行；小节导航紧贴谱面，快捷键帮助放在题头。
- 击拍起点直接在谱面上用竖线标记，不增加位置说明文字。点击吸附到音符或休止符，拖动、滚动及行间留白不改起点；定位不滚动或播放，运行中禁止修改，桌面悬停显示淡色预览。
- 把主要操作和辅助操作分组；长题名和工具栏自然换行，不靠挤小点击区域解决溢出。
- 预留必要的结果／校验提示空间，避免反馈出现时推动谱面。浮动操作提示与字段错误采用不同位置。
- 会话列表通过三点菜单提供重命名和删除；重命名和删除确认共用居中模态弹窗样式，保存失败保留草稿，删除失败在弹窗内重试。操作入口的显隐独立于禁用态；切换等待复用列表的加载反馈，不挤动消息区，新会话在首帧绘制前完成滚动定位。
- 异步界面区分首次加载、已有内容更新和读取失败。首次加载用稳定占位，更新保留上次结果及其统计口径，完成后整体替换；提示预留空间，短请求不显示加载文字，失败保留结果并提供重试。
- 请求与缓存由 TanStack Query 管理，列表／详情用 `ui/useRetainedData` 保留上次展示结果直到新查询成功，失败时仍保留；加载反馈复用 `ui/AsyncStatus` 和 `LoadingPlaceholder`。跨题身份不借用旧作答或成绩；训练重建仍用于释放旧音频。
- 击拍谱面可按行跟随，用户手动浏览后暂停自动跟随；听写作答、编辑和参考答案保持各自的浏览位置。
- 只读参考答案与用户作答分开，查看答案不得触发作答编辑或通过判定。

- 路由切换不做整页淡入；模块未就绪时通过稳定的 Suspense 边界保留已显示正文，首次打开仍使用加载占位。页面就绪后在绘制前恢复滚动与焦点，训练与编辑仍按访问重建。

## 交互、焦点与错误

- 所有操作有可访问名称及可见键盘焦点；选中状态与焦点状态分开。
- 焦点提示统一由 `ui/focusVisibility` 区分操作路径：鼠标操作后，Esc 和练习字母快捷键不启用描边；Tab、方向键、Enter、空格等键盘导航恢复原生提示。弹层关闭仍恢复触发点，下拉选择与按钮统一区分鼠标和键盘焦点，文本输入保留原生聚焦样式；不得逐个入口用失焦掩盖恢复问题。
- 全局练习字母快捷键避开输入、可编辑区域、选择控件、输入法组合输入和其他模态层；普通按钮和链接聚焦时仍可使用，实际执行时释放旧控件焦点。Tab、Enter 和空格保留原生导航与激活行为。
- 小型表单和确认弹窗复用 `ui/Modal`；确认通过 `ui/confirmation` 异步返回，调用方卸载即取消。标题说明操作，正文仅保留必要后果，不重复长名称；取消在左，主操作在右，破坏性操作使用危险色。
- 模态浮层隔离背景焦点，共享 `ui/modalScroll` 嵌套滚动锁；关闭恢复合理触发点。表单和确认通过按钮或 Esc 关闭，抽屉和预览可按场景支持点击遮罩。浏览器刷新／关闭时的未保存提示保留原生行为。
- 离开训练或关闭练习先停止音频，再完成视觉退出；快速开关和布局切换不能遗留关闭回调。
- 系统减少动态效果时关闭相关动效，声音和必要状态反馈仍可用。
- 字段错误靠近字段并帮助定位，读取失败在内容区提供重试；保存失败保留草稿并提供重试，错误不自动消失。
- 破坏性操作明确范围并确认，普通编辑操作避免不必要的确认。成功提示短暂显示，重复失败仍可再次呈现。

## 验收范围

共享布局先验证击拍与听写，再检查受影响的列表、编辑器或设置。按本次改动的影响范围检查桌面、助手展开、长内容、主题／明暗模式、键盘与减少动态效果；窄屏和断点检查按需进行，不作为默认必检项。
播放或保存相关变化还需验证关闭／离页、失败重试与状态恢复；回归脚本见前端 README。
