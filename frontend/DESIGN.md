# 界面设计系统

与代码基线 `c868670` 核对于 2026-09-16。本文描述当前界面规则；历史取舍见 [UI／UX 历史复盘](UI-UX-RETROSPECTIVE.md)，调整方法见 [UI／UX 调整流程](UI-UX-WORKFLOW.md)。具体行为与运行说明见 [前端 README](README.md)。

## 目标与参照

友好、清楚、有按压反馈的节奏训练界面。早期设计借鉴多邻国的圆润控件、清晰主次与即时反馈，不复制品牌、角色、字体文件、图标、音效或页面布局。早期参照限于公开首页及登录入口，未确认的登录内页细节不作为规范。

本站使用自行绘制的节拍器品牌标记；导航与通用操作图标使用 `lucide-react`，音乐符号沿用谱面的记谱规则。

## 基本规则

| 项目 | 当前规则 |
| --- | --- |
| 配色 | 默认紫色，可选蓝色、青绿色；配色与明暗模式独立，默认跟随系统，也可固定浅色或深色 |
| 表面与谱面 | 页面、工作区、输入框、边框和谱面使用语义变量，随明暗模式调整；不固定为白底黑谱 |
| 文字 | 本地中文系统字体，正文 16px、说明 14px；标题与操作强调主次，尺寸按页面和可用宽度调整 |
| 控件 | 通用操作按钮使用 12px 圆角、2px 描边、4px 按压厚度；导航行、分类按钮和分段选择有各自的平面规则 |
| 间距 | 4、8、12、16、24、32、48px；页面布局选用这些档位 |
| 状态 | 默认、悬停、按下、键盘焦点、禁用；选中状态与悬停分开，错误输入保留文字提示 |
| 反馈 | 成功／错误保持固定语义，具体前景与底色适配明暗模式；结果保留文字，谱面判定使用不同形状与颜色 |
| 动效 | 通用控件 140ms；减少动态效果偏好下禁用相关位移、过渡和节拍器摆动 |

主操作依场景确定：击拍、播放题目、验证或保存；试听为次操作。停止使用可辨识的错误语义色。主按钮使用主题前景和底色，悬停使用对应主题的悬停色，不固定为紫底白字。

通用键盘焦点圈为 2px、外距 2px；导航焦点圈内收，避免裁切。小节数选择使用原生 radio，支持方向键。BPM 数字输入隐藏原生增减箭头，保留键盘上下键；拖动滑块松手生效，数字输入失焦或回车生效，不提供单独的“应用速度”按钮。

## 导航与页面框架

- `SiteNavigation` 统一提供首页、预设练习、随机练习、自定义练习和设置入口。桌面采用固定侧栏，正文独立滚动；侧栏可折叠为图标，仍保留可访问名称与提示，折叠偏好保存在本地。存储不可用时本次会话仍可折叠。
- 视口宽度不超过 1000px 时改用移动页头和左侧模态菜单。支持菜单按钮打开、关闭按钮、Esc、点击遮罩和选中链接关闭；打开期间锁定页面滚动，路由变化或切回桌面也关闭菜单。
- 当前页或所属栏目用 `aria-current`、主题色和选中底色表示；悬停使用独立浅底。导航不使用悬停下拉、当前项小勾或按钮按压厚底。
- 正文最大内容宽度为 1440px，按实际可用宽度与响应式留白收缩。页面标题、返回栏和内容遵循正文基准线；全站侧栏与预设主题／设置分类侧栏是不同层级。
- 首页三个练习来源保持平级，使用带图标、说明和箭头的整行链接；首页、随机和自定义模式入口共用导航行反馈。未开放模式显示“未开放”，不提供链接或可点击反馈。
- 预设列表桌面采用主题导航与题目区两列，两区独立滚动；题目区标题与模式选择固定，宽度不足时模式换行。窄屏改用主题选择框及页面滚动。题目使用整行链接、淡分隔线、悬停底色和焦点轮廓，不使用按压厚底。
- 练习详情共用 `PracticeHeading`：预设与自定义显示返回入口及题名，随机只显示返回入口；长题名自然换行。返回入口遵守历史恢复规则，直达时有普通链接兜底。
- 自定义列表提供新建、空态引导、加载／读取错误及分页；暂不展示未开放的编辑按钮。保存返回时以主题选中底色和“已保存”提示对应题目。
- 404 使用轻量状态页：错误码、标题和一个主操作入口。普通失效地址返回首页，失效预设题目返回预设练习。

## 练习工作区

- 击拍和听写共用 `PracticeFrame`：顶部操作栏、谱面内容区和设置区；框架不持有播放或作答状态。设置在 DOM 中先于谱面，宽屏置右、窄屏置上，不因重排重挂载练习。
- 自定义新建页沿用相同的工作区布局规则：顶部名称、试听及保存，主区为谱面与编辑工具，设置区为节拍器、BPM 与小节数量。保存错误在顶部，超拍提示靠近编辑工具。
- `PracticeSettings`、`RhythmTrainer`、`RhythmDictation` 和 `RhythmEditor` 各自拥有对应样式，不依赖来源页面传入设计系统开关。三类题目来源复用训练组件，来源专属操作留在页面或操作栏扩展位置。
- 随机练习首次进入生成默认两小节题目，不自动播放、不自动打开设置。生成抽屉按音符、休止符和节奏型分组，用原生复选框及记谱预览表示材料；关闭保留配置，工作区“换一题”才应用。抽屉内不再提供生成提交按钮；错误靠近范围标题，选项区独立滚动。
- 听写与自定义新建共用编辑器；基础符号、节奏型和编辑操作分组，按内容区可用宽度换行。小节导航不使用按压位移；作答与只读参考答案保持独立选择和浏览状态。
- 作答、编辑及参考答案采用可横向滚动的单行谱面；击拍使用多行谱面与按行跟随。谱面缩放、音符和反馈使用一致坐标，返回恢复后选中小节应进入视野，后续手动滚动不被抢回。
- 预备拍与整题结果覆盖谱面窗口，不占布局空间、不覆盖顶部操作或设置。结果使用语义色实底、图标与文字，并提供可访问的关闭操作；按压动画不移动谱面。
- 通用播放、停止和准备状态由 `RhythmPlayback` 负责。更改速度停止旧播放，保留编辑草稿；离开页面停止音频。详细恢复和生命周期规则见 [README](README.md) 与 [TIMING](TIMING.md)。

## 设置与账号

- `/settings` 提供账号、外观、本地数据、声音、击拍精度五个分类，默认账号；`category` 查询参数选择分类，未知值回退账号。切换分类替换当前历史记录，避免逐次增加后退步骤。
- 宽屏左侧分类、右侧内容，窄屏分类移到上方并换行，手机使用两列。分类是平面按钮，选中用主题色与底色表达，保留独立键盘焦点。
- 登录、退出、账号状态及会话重试都在账号分类，主导航不显示独立登录／退出控件。`/login` 替换重定向到 `/settings?category=account`；登录成功原位显示账号，退出后原位恢复表单。
- 登录表单左对齐、最大宽度 400px，保留标签、自动填充和焦点。发送验证码为次操作，登录为主操作；字段错误紧跟对应输入并关联辅助说明，发送成功聚焦验证码框，服务错误位于提交按钮上方。
- 外观包含紫／蓝／青绿色配色，以及跟随系统／浅色／深色模式，两者独立选择、立即生效。恢复默认同时重置为紫色与跟随系统，不影响题库、账号或击拍精度。
- `settings/appearance.ts` 在 React 渲染前恢复外观；非法或读取失败时回退默认，保存失败时本次选择仍生效并提示。偏好只保存在当前浏览器，不与账号或其他标签页实时同步；跟随系统时响应系统明暗变化。
- `data-theme` 与 `data-color-mode` 控制根节点语义变量，嵌套 `.design-system` 不重置配色。谱面使用 `--ds-score`，符干继承相应颜色；试听高亮随主题变化，成功／错误保留各自语义。
- 击拍精度已提供宽松、标准和严格三档，新设置从下一轮生效；声音分类仍标注未开放，不提供无效控件。本地数据展示统计，清空前确认，不提供练习入口。

## 样式归属与迭代

样式位于 `src/design-system.css`，通过 `.design-system` 启用控件规则；全局框架同时使用 `src/App.css`。类名按职责命名，不添加版本后缀。优先修改共同变量和控件规则，再判断页面是否确实需要例外；不为纯样式建立转发组件。

调整共享布局时先验证主要样板与异质样板，例如击拍加听写；涉及编辑保存则加入自定义新建，涉及导航则加入列表与设置。通过后再推广，方法与完整验收清单见 [UI／UX 调整流程](UI-UX-WORKFLOW.md)。

重点验收桌面与 390px 窄屏、断点两侧、侧栏展开／折叠、移动菜单及键盘关闭、三种配色与明暗模式、实际谱面和反馈、账号状态、空列表和加载、BPM 非法输入、返回恢复及音频停止。样式或结构变化后同步修改本文对应规则，不只追加新说明。
