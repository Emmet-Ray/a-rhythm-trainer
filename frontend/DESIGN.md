# 界面设计系统

## 目标与参照

友好、清楚、有按压反馈的节奏训练界面。借鉴多邻国的圆润控件、清晰主次与即时反馈，不复制品牌、角色、字体文件、图标、音效或页面布局。

参考入口：[学习](https://www.duolingo.com/learn)、[课程](https://www.duolingo.com/lesson)、[排行榜](https://www.duolingo.com/leaderboard)、[任务](https://www.duolingo.com/quests)、[商店](https://www.duolingo.com/shop)、[账号设置](https://www.duolingo.com/settings/account)。本轮匿名访问无法查看完整登录内页，实际可见参照是公开首页及登录入口；不将未查看的内页细节作为已确认规范，后续可结合用户截图迭代。

## 基本规则

| 项目 | 当前规则 |
| --- | --- |
| 品牌 | 紫色 `#7052d6`，白色底面；不以多邻国绿色或吉祥物作为识别元素 |
| 文字 | 本地中文系统字体，正文 16px、说明 14px，标题 28–36px；标题与操作加重 |
| 形状 | 控件圆角 12px、入口圆角 20px；2px 描边，4px 按压厚度 |
| 间距 | 4、8、12、16、24、32、48px；页面布局选用这些档位 |
| 状态 | 默认、悬停、按下、键盘焦点、禁用；错误输入保留文字提示 |
| 反馈 | 成功深绿配浅绿底，错误深红配浅红底；同时显示文字，不只依赖颜色 |
| 动效 | 控件 140ms；按钮下压、开关滑动；减少动态效果偏好下禁用位移和过渡 |

主按钮用于开始击拍；次按钮用于试听或应用设置；停止是可辨识的红色描边操作。描边容器只用于可点击入口，不给所有页面区域套卡片。

生成主按钮悬停仍为深紫底白字，按下收起厚底。焦点圈统一为 2px、外距 2px。小节数使用原生 radio 的分段单选，支持方向键切换；BPM 隐藏原生增减箭头，保留数字输入及键盘上下键。

导航状态独立表达：当前位置用紫色加粗文字，下拉当前项另有小勾；悬停用浅灰紫底。菜单展开只改变箭头和浅底，不代表当前位置。键盘焦点保留独立框线。下拉浮层使用轻阴影、不使用按压厚底；与触发器相隔 8px，透明命中区保持鼠标移入连续。

## 试验范围

- 样式位于 `src/design-system.css`，通过 `.design-system` 显式启用，不修改旧页面的全局设计变量。
- 首页 `/`：三个入口等权重，图形为本站自行绘制的 SVG，不使用外部品牌素材。
- 公共页头：所有页面统一字体、导航、登录/退出及下拉样式；只在 header 上启用，不影响未迁移页面主体。
- 预设列表 `/preset`：保留主题结构，训练方式使用平面分段选择，当前项描边高亮；题目入口使用更紧凑的 3px 按压厚度。主题之间仅分隔，不加外层卡片。
- 预设练习页 `/preset/:questionId`：击拍和听写共用页面布局 `practice-page`，这里只负责宽度、标题和返回入口。
- 随机练习：入口、生成配置、公共设置与击拍区启用新样式；主题多选保留原生复选框，选中使用紫色描边与浅底，不使用按压厚度。桌面两列、窄屏单列。修改范围不换题，提交生成才应用。
- 听写组件自身启用 `rhythm-dictation`：题目播放为主操作，停止为红色描边，范围选择保持平面；文字编辑工具继续分组，小节选择不使用按压位移。验证和整题反馈预留空间，以文字和颜色共同表达结果。预设听写的页头与设置同步启用。
- `PracticeSettings`、`RhythmTrainer`、`RhythmDictation` 自身分别启用 `practice-settings`、`rhythm-trainer`、`rhythm-dictation`，不依赖来源页面或样式开关。三种来源的练习自然保持一致；共享设置在自定义新建页也统一更新。
- `RhythmEditor` 自身启用 `design-system`，编辑工具、提示和小节选择样式归属 `rhythm-editor`，听写与自定义新建页自动一致。参考答案仅绘谱，不带编辑选择样式。
- 自定义入口与列表启用设计系统：模式入口复用随机入口规则；题目链接与未开放的编辑操作分离，新建入口为主操作，来源、加载、空列表、读取错误和分页保留原有语义。
- 自定义新建页采用公共页面宽度与标题，名称、小节数量和保存区统一控件样式；保存为主操作，错误保留文字提示，窄屏表单与保存按钮换行。编辑及保存逻辑不变。登录页暂不换皮。
- 通用播放按钮、停止状态和播放提示归属 `RhythmPlayback`，组件自身启用设计系统；听写仅保留“播放题目”为主操作的规则，自定义试听使用次按钮。
- 类名按职责命名，不添加版本后缀；历史由版本控制管理。
- 谱面、声音、时间线、判定和操作流程不变。反馈区预留高度，按压动画只移动按钮，不移动谱面。

## 如何迭代与推广

随机练习入口的三种方式保持同级排版；未开放的几何游戏共用入口尺寸和标题位置，以浅灰底及右侧“未开放”表达状态，无链接、按压厚度或悬停反馈。

先修改变量和控件规则，再判断是否需要页面布局例外。不要通过不断叠加局部样式来修补同一种控件。

确认首页和击拍样板后，再逐页启用；出现新控件时才补规则。暂不引入组件库，不为纯样式建立转发组件。

验收：桌面与 390px 窄屏；页头在登录、未登录与加载状态下可换行；下拉悬停与键盘关闭；主题内训练方式切换和空题库；键盘焦点；按钮按下/禁用；BPM 非法输入；节拍器开关；预备拍、试听、停止、击拍及结束反馈。检查动画不造成谱面位移，退出页面后旧音频停止。
