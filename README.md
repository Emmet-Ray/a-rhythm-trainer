# 节奏训练

面向音乐自学者的节奏训练工具，哪里不会练哪里：练什么内容、多少BPM、练哪一小节，都由你自己掌控。

![AI 助手根据乐谱图片生成节奏练习，支持试听并打开练习面板](docs/media/overview.png)

## 核心功能

- **按自己的需要练**
  - **击拍与听写**：支持击拍练习、节奏听写练习。
  - **自选内容**：预设题目、随机生成、自定义编写，或由 AI 根据文字、乐谱图片辅助出题；支持编辑 AI、随机和自定义题目，并保存到自己的题库。
  - **针对难点练习**：击拍时可从指定小节练到结尾，也可只练当前小节；听写支持单小节播放、逐小节作答与验证；自由调整 BPM，选择适合自己的速度。

- **AI 节奏助手**
  - 支持多轮问答、节奏讲解，以及文字和乐谱图片输入。
  - 根据你的要求生成对应的击拍或听写练习题目。
  - 结合当前题目和练习表现，帮助分析问题、提供练习建议。
  - 支持通过 **DeepSeek API Key** 或 **ChatGPT 订阅授权**接入模型。

- **练习记录与复盘**
  - 保存击拍与听写记录，查看每道题的历史结果和单次练习详情。
  - 按时间、练习模式筛选，查看练习次数、练习天数及次数趋势。

## 功能演示

### 击拍练习

试听节奏，按空格键击拍，查看每次击拍的准确度与整轮结果。

### 节奏听写

聆听题目，填写节奏，逐小节验证答案，完成整段节奏听写。

## 快速启动（Docker）

1. 下载项目并复制配置文件：

   ```sh
   git clone https://github.com/Emmet-Ray/a-rhythm-trainer.git
   cd a-rhythm-trainer
   cp .env.example .env
   ```

2. 启动：

   ```sh
   docker compose up -d --build
   ```

打开 <http://localhost:8080> 即可使用。使用 AI 助手前，在「设置 → 模型服务」中配置模型。

## 技术栈

- **前端**：React、TypeScript、Vite；React Router（路由）、Lucide（图标）、react-markdown（Markdown 渲染）、VexFlow（谱面渲染）、Web Audio API（音频与节拍调度）；AI SDK UI（助手流式消息）
- **后端**：Python、FastAPI；SQLite、SQLAlchemy、Alembic（数据存储与迁移）；Pydantic AI（模型接入与工具调用）、OpenAI Python SDK（DeepSeek 与 ChatGPT 订阅 Responses）
- **部署**：Docker、Nginx
